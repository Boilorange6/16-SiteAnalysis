# A0 원천 검증표

작성 시작: 2026-09-29 · 기준 스펙: docs/superpowers/specs/2026-09-29-site-analysis-v2-design.md

판정: ✅ 사용 가능 / ⚠️ 조건부 / ⛔ 차단 / ⏳ 사용자 조치 대기

사용 범위: 산출물은 **회사 내부 업무용**이다. "내부 업무 사용" 칸은 이 범위만 판단한다. 외부 전달·공개 서비스로 바뀌면 다시 검토한다.

읽는 법
- 라이선스 칸의 따옴표 안은 원천 페이지 문구를 그대로 옮긴 것이다(2026-09-29 조회).
- "원본 크기"는 받은 파일의 바이트 수다. 받지 않은 원천은 페이지에 적힌 크기를 `페이지:`로 표시한다.
- "검수지 8곳 행 수"는 좌표가 있으면 측정 도구의 반경 1,000 m 집계다(`bySite`). 좌표가 없으면 검수지가 속한 **시군구 전체** 행 수를 `시군구:`로 따로 적는다. 두 값은 비교할 수 없다.
- 순서: guryong / dasan / cheongwadae / jeongja / marinecity / bokjeong / sejong / wanju.
- 측정 JSON: `docs/superpowers/a0/measurements/`. 원본은 `.cache/v2/raw/<source_id>/`(gitignore)에 있다.
- 채움률은 측정 도구 기준이다. 빈 문자열·`null`·`-`만 미기재로 센다. **건축물대장은 미상을 `0`으로 적기 때문에** 숫자 필드는 "0이 아닌 비율"을 따로 적었다(`*-extra.json`).
