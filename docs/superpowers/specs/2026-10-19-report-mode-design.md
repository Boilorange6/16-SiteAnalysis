# 보고서 모드 설계

- 날짜: 2026-10-19
- 시안: https://claude.ai/artifact/U2a9YuKdD6JvNtibNM7NWj (공통 1장 + A·B·C 컨셉 각 4장)
- 사용자 결정: **A 스튜디오를 바탕으로, B의 수치 맞춤·위치도와 C의 레이아웃 바꾸기·발표 메모·쓰임 먼저 내보내기를 더한다** (2026-10-19, "너의 추천대로").
- 벤치마킹 근거: `scratchpad/report-research/` 의 Aside 조사 3건(캔바·Gamma·Pitch / ArcGIS·QGIS·Felt / Figma Slides·Google Slides·Beautiful.ai·PowerPoint Designer·Tome).

## 1. 의도

앱의 화면을 두 가지 모드로 나눈다.

- **타일 모드**: 웹에서 분석 결과를 보는 곳이다. 지금의 보드 그대로이고, 보고서와 관련된 기능은 모두 빠진다.
- **보고서 모드**: 내보낼 문서를 만드는 곳이다. 결과물은 PPT·PDF·이미지이고, 오프라인 열람과 발표에 쓴다.

지금의 PPT 미리보기(`report-preview.tsx`)는 모달 안에서 페이지를 조금 고치는 도구다. 이것을 페이지 자체가 편집기인 작업 공간으로 키운다. 사용자는 실제 내보낼 레이아웃 위에서 범례·라벨·지도 확대·위치를 직접 맞춘다.

## 2. 목표

1. **모드 전환**
   - 머리 줄 가운데에 `타일 | 보고서 · n쪽` 전환을 둔다.
   - 분석 직후에는 타일 모드다.
   - 보고서 모드에 처음 들어가면 페이지가 0쪽이다. 안내 문구 **"페이지를 추가하세요"** 와 함께 `+ 페이지 추가`, `추천 구성으로 시작` 버튼을 보여 준다.
2. **편집 화면 (A 스튜디오)**
   - 왼쪽에 도구 레일을 둔다: 페이지 / 분석 타일 / 글상자 / 테마. 그 옆에 서랍(약 312 px)이 열린다.
   - 가운데는 판형 그대로의 캔버스다.
   - 아래에 페이지 줄을 둔다. 썸네일, `+ 페이지`, 끌어서 순서 바꾸기를 지원한다.
   - 선택한 요소 위에 떠 있는 툴바가 뜬다.
   - 머리 줄에는 문서 이름, 저장 상태, 실행 취소·다시 실행, 판형, 발표 미리보기, 내보내기를 둔다.
3. **페이지 추가**
   - 페이지 종류는 다음과 같다:
     - 표지 (주소·반경·작성일 자동 입력)
     - 분석 타일 한 장
     - 여러 타일 비교 (2×2 · 3×2 · 3×1)
     - 출처·기준일
     - 빈 페이지
   - "분석 타일" 서랍에서 고르는 방법은 세 가지다: 검색, 분류 칩, `+`, 끌어다 놓기.
   - 이미 넣은 타일에는 `n쪽에 있음`이 표시되고, 같은 타일을 다시 넣을 수도 있다.
   - 추가 직후 "되돌리기" 토스트를 띄운다.
4. **지도 프레임 편집** — 가장 중요한 기능이다.
   - 지도를 두 번 누르거나 `지도 이동` 버튼을 누르면 지도 안으로 들어간다. 그 상태에서 끌어 이동하고 휠이나 `+/−`로 확대한다. Esc나 바깥을 누르면 끝난다.
   - `대지에 맞추기`, `반경 전체 보기`, `지도 위치 고정` 버튼을 둔다.
   - 축척을 숫자로 보여 주고 직접 입력도 받는다(`1:2,500`). 프리셋은 1,000 / 2,500 / 5,000 / 10,000이다. 중심 이동량(동·북 m)도 숫자로 입력한다(B에서 가져온 것).
   - 배경지도는 일반 / 도로 / 항공 / 없음 중에서 고른다.
   - 레이어마다 켜고 끌 수 있다.
   - 라벨 규칙은 대지 주변 지번만 / 보이는 지번 모두 / 끄기 중에서 고르고, 고정 라벨을 둘 수 있다.
   - 범례:
     - 항목을 켜고 끄고 순서를 바꾼다. 끌어서 옮기거나 `↑↓` 버튼을 쓴다.
     - 위치는 지도 아래 / 오른쪽 / 숨김 중에서 고른다.
     - `보이는 것만` 옵션은 지도 범위 밖 항목을 자동으로 뺀다.
   - 지도 장식: 방위표, 축척 막대, **위치도**(넓은 범위에 대지를 표시하는 작은 지도, B에서 가져온 것).
   - 이 설정은 **페이지마다 따로** 저장한다. 타일 카드에는 영향이 없다.
5. **레이아웃 바꾸기 (C)**
   - 선택지는 지도 크게 / 지도 + 요약 / 숫자 먼저 / 다른 타일과 나란히다.
   - 바꿔도 지도 위치·확대·범례 설정은 유지한다.
6. **발표 메모 (C)**
   - 페이지마다 메모 칸을 둔다.
   - PPT로 내보내면 슬라이드 노트로 들어간다.
7. **판형**: 16:9 와이드(기본), A3 가로, A4 가로. 판형을 바꿔도 내용은 다시 배치되고 지도 상태는 유지된다.
8. **내보내기 (A 팝오버 + C 쓰임 먼저)**
   - 먼저 쓰임을 고른다:
     - 발표 → PPT. 도형 편집 가능, 메모 포함.
     - 인쇄·제출 → PDF. 판형 그대로, 고해상도 지도.
     - 붙이기 → PNG. 쪽마다 한 장, 여러 쪽이면 zip.
     - 모두 한 번에 → zip.
   - 이어서 페이지 범위, 파일 이름, PPT의 지도 그리기 방식(편집 가능한 도형 / 이미지 한 장)을 정한다.
   - **내보내기 전 확인**: 범례가 넘침, 축척·방위표 없음, 출처 페이지 없음 같은 문제를 보여 주고, `n쪽 보기`로 바로 이동하게 한다.
9. **저장**
   - 보고서 구성은 프로젝트의 일부로, 지금의 `저장` 버튼으로 보드와 함께 서버에 저장한다.
   - 저장하지 않은 변경이 있으면 머리 줄에 표시한다(`저장 안 됨`).
   - 브라우저 임시 저장(`analysisId` 키)으로 새로고침해도 잃지 않게 한다.
   - 실행 취소와 다시 실행을 지원한다.
   - *(Claude 판단: 서버 자동 저장은 v1 범위가 아니다. 시안의 `저장됨 · 시각` 자리는 이 상태 표시로 쓴다.)*
10. **타일 모드 정리** — 다음 기능을 모두 제거한다:
    - 머리 줄 `내보내기 ▾`의 PPT·미리보기 (3D·CAD 파일은 §8-1)
    - 카드의 `보고서` 체크
    - ⋯ 메뉴의 `보고서에 포함`·`보고서에 넣을 그림`
    - 상세 창의 `보고서 출력`·`보고서 설명표 페이지 수`·포함 체크

    같은 기능은 보고서 모드의 페이지 설정에서 다룬다.

## 3. 비목표

- 여러 사람이 함께 편집하기, 댓글, 버전 기록 탐색
- 자유 그리기, 도형 라이브러리, 사진 업로드 (글상자만 넣는다)
- 지도 위 인출선·거리 측정 같은 `지도 표식` 도구 (시안 레일에 있었으나 다음 단계로 미룬다)
- 테마 여러 벌. v1의 테마는 지금 PPT 스타일 하나이고, 레일의 `테마` 자리는 판형과 글꼴 크기 정도만 다룬다.
- 인쇄용 CMYK 보정과 도련

## 4. 실패로 보는 것 (기능은 돌아가도)

- 모달 형태로 돌아가는 것. 보고서 모드는 페이지 자체가 작업 공간이어야 한다.
- 보고서에서 바꾼 지도 확대·범례가 타일 카드에 번지거나, 그 반대가 일어나는 것.
- 내보낸 파일이 편집 화면과 다르게 나오는 것. 원칙은 "화면 = 보고서"다(디자인 언어 §1).
- 끌기로만 할 수 있는 조작. 순서 바꾸기·추가·범례 순서 모두 버튼이나 키보드로도 할 수 있어야 한다.
- 호버로만 뜨는 기능, 44 px보다 작은 조작 영역.
- 편집 내용을 잃는 것. 새로고침, 분석 다시 실행, 주소 변경에서도 보고서가 남아야 한다.

## 5. 제약

- `docs/design/v2-design-language.md`를 따른다:
  - 글꼴은 Do Hyeon / Noto Sans KR이다.
  - 색 토큰은 `#15171c` / `#676c76` / `#d9dce2` / `#eef0f3`이다.
  - 레이어 색과 라벨은 `map-layers.ts` 한 곳에서만 정한다.
  - 숫자 서식은 `formatMetricValue`를 쓴다.
  - 추정값에는 `추정` 배지를 붙인다.
- 새 화면 패턴(모드 전환, 서랍, 페이지 줄, 지도 프레임 편집)은 승인된 시안을 근거로 디자인 언어 문서에 추가한다.
- PPT 생성은 기존 파이프라인(`report-plan.ts`, `render-pptx.ts`, `map-pptx.ts`, 편집 가능한 도형)을 확장한다.
- 지도는 기존 `MapFigure` 계열로 그린다.
- 주 대상 폭은 데스크톱 1280–1440 px이다.
- 새 npm 의존성은 사용자 승인 없이 넣지 않는다. PDF·PNG 생성 방식은 계획 단계에서 정한다.

## 6. 정해진 구조 (구현자가 따를 것)

- **보고서는 보드에서 독립된 페이지 목록이다.**
  - 지금의 `ReportState`(보드 순서·`included`·`faces`에서 파생한 페이지 + `styles` + `extra`)를 다음 구조로 바꾼다:

    ```
    { format, pages: ReportPage[] }
    ```

  - `ReportPage`가 담는 것:
    - 종류
    - 들어간 타일
    - 레이아웃
    - 지도 프레임마다의 상태: 확대, 이동, 축척 고정, 배경, 레이어, 라벨, 범례 항목·순서·위치, 장식
    - 제목·요약 글자 덮어쓰기
    - 글상자
    - 발표 메모
- 보드의 순서·크기·카드 면은 보고서에 영향을 주지 않는다.
- 페이지가 참조하는 타일 결과는 분석 결과에서 읽는다. 결과가 다시 계산되면 페이지의 사용자 설정은 유지하고 숫자와 지도만 새로 그린다.

## 7. 구현자에게 맡기는 것

- 서랍·페이지 줄·툴바의 세부 치수와 애니메이션. 150–200 ms, `prefers-reduced-motion`을 지킨다.
- 축척 숫자와 내부 확대 값 사이의 변환 방식
- `보이는 것만` 범례를 계산하는 방식
- 내보내기 전 확인의 판정 규칙(구체 기준)
- 추천 구성의 기본 페이지 순서. 타일 카탈로그 분류 순서를 따르는 것을 기본으로 한다.

## 8. 빌더 점검 뒤 정한 것

### 사용자 결정 (2026-10-19)

- **기존 저장본**
  - 새 보고서 모드는 항상 0쪽에서 시작한다.
  - 저장본에 옛 보고서 구성(`report.styles`·`extra`·`included`·`faces`)이 있으면 빈 화면에 `이전 보고서 구성 불러오기` 버튼을 둔다.
  - 누르면 옛 구성을 새 페이지 목록으로 바꾼다. 페이지별 지도 확대·이동·고정 라벨·숨김·패널 위치를 옮긴다.
  - 불러온 뒤에는 되돌리기로 취소할 수 있다.
- **PDF**
  - 새 의존성 없이 지금 있는 `html-to-image`로 쪽마다 고해상도(인쇄용 300 dpi 상당) 이미지를 만들어 PDF로 묶는다.
  - PDF 안의 글자는 검색할 수 없다. 이것은 받아들인 한계다.

### Claude 판단 (구현자가 따르되, 사용자가 문서를 읽으며 바꿀 수 있음)

1. **3D·CAD 내보내기**
   - DXF·GLB·DAE·3DM은 보고서가 아니라 데이터 내보내기다. 그래서 타일 모드 머리 줄에 `파일 ▾`로 남긴다.
   - PPT 항목과 `미리보기`만 타일 모드에서 빠진다.
2. **주소 변경**: 보고서는 그 분석이나 프로젝트에 속한다. 새 주소로 분석하면 새 보고서(0쪽)가 되고, 옛 보고서는 옛 프로젝트를 다시 열면 그대로 있다. 다른 대지로 구성을 옮겨 쓰는 기능은 없다.
3. **페이지 1개 = 출력 1쪽**
   - 원칙은 "화면 = 보고서"다.
   - 여러 장이 나오는 타일은 넣을 때 페이지 여러 개로 펼친다:
     - 설명선 타일(A05·A06)은 개요와 설명표 장수만큼
     - 컷 타일(S01·S02·S03·S04·D22)은 컷 조판·단일 장
     - 앞·뒷면을 모두 넣으면 2장
   - 펼친 페이지는 각각 독립적으로 고친다.
   - 예외: `출처·기준일`은 한 페이지로 다루되, 14행을 넘으면 내보낼 때 다음 쪽으로 넘어가고 썸네일에 `+n쪽`으로 표시한다.
4. **타일 내용 설정은 페이지가 갖는다**
   - 대상: 컷·카메라·계절(`cuts`·`cameras`), `a05Filter`, 래스터 `layers`, 고정 `labels`, 설명표 장수, 앞·뒷면.
   - 페이지에 넣는 순간 보드의 값을 복사하고, 그 뒤로는 따로 간다.
   - 타일 모듈의 보고서 훅(`cut.plan` 등)은 페이지 상태를 받도록 고친다.
5. **서랍 목록**: 원본 분석 타일(33개)만 보여 준다. 보드의 복제본·스택·조판은 보고서로 넘어가지 않는다. 비교가 필요하면 `여러 타일 비교` 페이지를 쓴다.
6. **패널 자리**
   - 제목·요약·범례 패널은 지금 미리보기처럼 끌어서 옮기고 크기를 바꿀 수 있다. 맞춤선도 유지한다.
   - 레이아웃이나 판형을 바꾸면 패널은 그 레이아웃의 기본 자리로 돌아간다(되돌리기 가능).
   - 레이아웃 `지도 크게`는 지금처럼 지도가 쪽 전체를 채우고 패널이 위에 얹힌다. 나머지 레이아웃은 지도를 틀 안에 둔다.
7. **지도 위치 고정**
   - 실수로 끌거나 휠로 바꾸지 않게 막는 잠금이다.
   - 판형·레이아웃이 바뀌거나 결과를 다시 계산해도 항상 축척과 중심을 유지하고, 보이는 범위만 틀 크기에 따라 달라진다.
   - `대지에 맞추기`를 눌렀을 때만 다시 맞춘다.
