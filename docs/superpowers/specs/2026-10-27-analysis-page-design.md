# 2단계 분석 장(지도 + 그래프) 설계

작성 2026-10-27. 근거: 사용자 결정 3건(아래)과 1단계 스펙 `C:/Users/da/.claude/plans/declarative-painting-sunrise.md` §2단계.

## 왜
- 대치동 503의 아키맵 Site report 4장(11·12·14·17쪽)과 우리 PPT 실렌더(15·17·20·10쪽)를 나란히 비교했다. 사용자는 **4장 모두 아키맵이 낫다**고 판단했고, 조건을 하나 달았다. "단 라벨 표현과 범례 표현은 필요하다"([비교 페이지](https://claude.ai/artifact/53B8NnjD5fL7wwVs9qv15D)).
- 사용자 말: "아키맵을 보면 지도와 그래프 같은 요소가 필요해."
- 시안 A·B·C 가운데 **B**를 골랐다([시안](https://claude.ai/artifact/P1GbFUq7P6CrkztAkYC38k)). B는 큰 지도 하나를 왼쪽에 두고, 오른쪽 열에 위에서부터 다음을 쌓는다.
  1. 큰 숫자
  2. 한 줄 통계
  3. 구성비 막대
  4. 「대지에서 거리–값」 산점도
  5. 해석 문장
- 지금 장은 오른쪽에 긴 요약 문단과 작은 각주 여러 줄을 둔다. B는 이 자리를 그래프로 바꾼다.

## 목표
1. 타일 장에 새 레이아웃 **「지도 + 그래프」**를 더한다. 오른쪽 열은 위에서부터 다음 순서다.
   - 지금의 큰 숫자(`view.headline`) 그대로
   - 한 줄 통계: 그래프 자료에서 만든다. 예: `반경 1 km 안 건물 1,735동 · 중앙값 4층 · 최고 69층 · 1층 가정 548동`
   - 구성비 막대
   - 거리 그래프
   - 해석 문장: 지금의 `view.sentence` 또는 사용자가 고친 요약 그대로
2. **구성비 막대**는 범례 항목마다 지물 수를 센다. 색은 범례 색과 같고, 막대 오른쪽에 %를 쓴다. 모든 지도 타일에서 지금 자료만으로 만든다.
3. **거리 그래프**는 두 가지다.
   - 지물에 값이 있으면 산점도: x는 대지에서 거리(0–반경 m), y는 값이다. 중앙값은 실선, 평균은 점선으로 긋고, 대지 안 지물의 평균을 분홍 점으로 찍는다. 값이 없거나 추정인 지물은 점에서 뺀다.
   - 값이 없으면 거리대 막대: 100 m 간격으로 지물 수를 센다.
4. **엔진이 지물 값을 실어 보낸다.**
   - `MapFeature`·`MapPolygon`에 선택 필드 `value?: number | null`을 둔다. 결과의 `presentation`에는 `valueAxis?: { label: string; unit: string }`을 둔다.
   - 1차 대상: D05 지상 층수(1층 가정은 null), D04 사용승인 연도, 매매 실거래(10쪽) ㎡당 가격(만원).
   - 엔진 출력이 바뀌므로 `TILE_CACHE_REVISION`을 올린다. 값이 없는 옛 분석은 거리대 막대로 대신한다.
5. **화면 미리보기와 PPT가 같은 그래프**를 그린다. 공용 기하 모듈 하나가 그래프를 도형 목록(사각형·선·점·글자, 슬라이드 인치 좌표)으로 만든다. 화면은 이를 SVG로, PPT는 편집 가능한 도형으로 그린다.
   - PPT의 산점도 점은 범례 색마다 도형 하나(custGeom, 여러 하위 경로)로 묶는다. 점이 수천 개여도 도형 수가 늘지 않는다.
6. **범례는 지도 아래 띠.** 「지도 + 그래프」 레이아웃의 기본 범례 위치는 `지도 아래`다(이미 있는 프레임 설정). 범례 표현(점·선 견본, 이름)은 지금 것을 그대로 쓴다.
7. **각주(`reportSummaryNotes`)는 이 레이아웃에서 장에 그리지 않는다.** 대신 PPT 발표자 노트에 붙인다. 화면 미리보기에서는 오른쪽 열 맨 아래 `주석 N` 칩에 마우스를 올리면 보인다. 자료 한계 배지(일부 자료만 집계·추정)는 지금처럼 장에 남긴다.
8. 추천 구성: 그래프 자료가 있는 타일 장의 기본 레이아웃을 「지도 + 그래프」로 바꾼다. 「지도 + 요약」·「지도 크게」·「숫자 먼저」는 레이아웃 창에서 계속 고를 수 있다. 이미 저장된 보고서의 쪽은 바꾸지 않는다.

## 하지 않는 것
- 지도 두 장(A안), 2×2 칸(C안).
- 새 장 종류(대지 개요·지가 필지 지도 등): 3단계에서 한다.
- 월별 차트, 표.
- 사각 틀을 꽉 채운 지도: 반경 밖 자료를 엔진이 가져와야 해서 별도 작업이다.
- 그래프 hover 상호작용: 1차는 정적이다. 범례 hover 강조는 지금 그대로 둔다.

## 실패로 보는 것
- 그래프가 지도를 가린다(taste 강한 선호: 어떤 오버레이도 지도를 가리지 않는다).
- PPT 그래프가 그림(이미지)이다. 도형이어야 색·글자를 고칠 수 있다.
- 미리보기와 PPT의 그래프 값·순서·색이 다르다(mistakes #13).
- 영문 코드·내부 id가 그래프 축·라벨에 나온다.
- 각주에 있던 자료 한계(추정·미상)가 아무 데도 남지 않는다. 노트와 배지 둘 중 하나에는 반드시 남아야 한다.

## 정해진 것(사용자 결정)
- 배치는 B다. 지도 왼쪽 큰 것 하나, 오른쪽 열 순서는 큰 숫자 → 통계 → 구성비 → 거리 그래프 → 해석.
- 라벨(바탕 이름 라벨·주제 말풍선·지시선)과 범례 표현은 지금 것을 유지한다.
- 지도 틀은 지금 원 틀을 유지한다(사각 틀은 하지 않는 것 참고).

## 내가 정한 것(사용자가 바꿀 수 있음)
- 지도 폭은 지금 「지도 + 요약」 기하(`slidePanelRects`)를 그대로 쓴다. B 시안의 지도 폭 슬라이더 값은 받지 않았다.
- 오른쪽 열 세로 배분(요약 칸 높이 기준): 큰 숫자 20% · 통계 6% · 구성비 26% · 거리 그래프 32% · 해석 16%. 글자 크기 설정(`fontSizes.summary`)을 따라 비율을 유지한다.
- 구성비는 지물 수 기준이다(면적 기준 아님). 6개를 넘는 범례는 상위 5개와 「그 밖」으로 묶는다.
- 산점도 점은 반지름 1.7 px(화면 기준 장 1280 px 폭), 불투명도 0.45. 점이 2,000개를 넘으면 무작위가 아닌 거리순 균등 표본 2,000개만 그린다(PPT 크기 상한).
- 거리 축은 0–분석 반경이고, 눈금은 반경/4 간격이다.
