# PPT 내보내기 미리보기 + 공유 슬라이드 모델 설계

- 날짜: 2026-07-02
- 상태: 승인됨 (사용자 확인)
- 관련 코드: `src/lib/ppt-generator.ts`, `src/components/site-analysis-app.tsx`, `src/components/map-view.tsx`

## 배경과 목표

현재 "PPT 내보내기"는 버튼 클릭 즉시 지도 베이스맵을 캡처하고 pptxgenjs로 6~7장짜리 .pptx를 다운로드한다. 미리보기가 없어 결과물을 내보내기 전에 확인·선택할 수 없고, 슬라이드 디자인 품질이 낮다.

목표:

1. **보기 좋은 HTML 미리보기가 우선** — 내보내기 전에 슬라이드를 HTML로 확인한다.
2. **미리보기 = PPT 결과물** — 두 출력이 어긋나지 않아야 한다.
3. **PPT 요소가 살아있어야 한다** — 지도 베이스맵만 이미지, 제목·마커·범례·표·차트·텍스트는 전부 PPT에서 개별 선택·수정·이동 가능한 네이티브 요소.

## 확정된 요구사항 (사용자 답변)

| 질문 | 결정 |
|---|---|
| 미리보기에서 가능한 조작 | 보기 + 슬라이드 포함/제외 선택 (텍스트·레이아웃 편집은 범위 외) |
| 디자인 방향 | 풀블리드 비주얼형 유지 — 지도가 주인공, 타이포·패널 품질만 상향 |
| PPT 편집성 기준 | 지도만 이미지, 나머지 전부 네이티브 |
| 아키텍처 | 공유 슬라이드 모델 (SlideSpec 단일 소스) |

## 사용자 흐름 (UX)

1. 사이드바 "PPT 내보내기" 클릭 → **전체화면 미리보기 모달**이 열린다 (즉시 다운로드하지 않음).
2. 모달이 열리는 순간 1회 수행: 지도 베이스맵 캡처(`captureBaseMap`), POI/반경/노선 정규화 좌표 계산 → `SlideSpec[]` 생성.
3. 레이아웃:
   - 왼쪽: 슬라이드 썸네일 레일. 썸네일마다 체크박스로 포함/제외 선택.
   - 가운데: 선택된 슬라이드 대형 미리보기. 16:9 비율 고정, 좌우 화살표·키보드로 탐색.
   - 하단: "PPT 다운로드 (N장)" 버튼 — 체크된 슬라이드만 pptxgenjs로 생성.
4. 오류 처리: 지도 캡처 실패 시 플레이스홀더 배경(단색 + 안내 문구)으로 미리보기와 내보내기를 계속 진행하고 경고 배지를 표시한다.
5. 생성 중에는 기존 로딩 오버레이 스타일의 진행 표시를 모달 안에서 재사용한다.

## 아키텍처 — 공유 슬라이드 모델

슬라이드를 데이터(SlideSpec)로 정의하고, HTML 렌더러와 PPT 매퍼가 같은 데이터를 각자 그린다. 미리보기와 PPT의 일치는 구조적으로 보장된다.

```
분석 데이터 (config, POIs, 좌표, 노선, 베이스맵)
        │
        ▼
src/lib/slide-builder.ts        ← SlideSpec[] 생성 (디자인 결정은 전부 여기)
        │
   ┌────┴─────────────────┐
   ▼                      ▼
src/components/        src/lib/ppt-generator.ts
slide-renderer.tsx     (SlideSpec → pptxgenjs 얇은 범용 매퍼)
(SlideSpec → HTML)
```

### 파일 구성

| 파일 | 역할 |
|---|---|
| `src/lib/slide-spec.ts` | SlideSpec/SlideElement 타입 정의 |
| `src/lib/slide-builder.ts` | 분석 데이터 → 슬라이드 7장 SlideSpec 생성 |
| `src/components/slide-renderer.tsx` | SlideSpec 1장을 HTML로 렌더 (썸네일·대형 공용) |
| `src/components/export-preview.tsx` | 미리보기 모달 (썸네일 레일, 선택, 다운로드) |
| `src/lib/ppt-generator.ts` | 기존 슬라이드별 하드코딩 제거, SlideSpec → pptxgenjs 매퍼로 재작성 |
| `src/components/site-analysis-app.tsx` | 내보내기 흐름을 모달 열기로 변경 |

### SlideSpec 요소 타입

좌표는 슬라이드 기준 0~1 정규화 값. HTML은 %로, PPT는 13.333×7.5인치로 환산한다.

- `image` — 풀블리드 베이스맵 (data URL)
- `rect` — 패널, 액센트 바, 스크림 (fill+투명도, 둥근 모서리, 그림자, 테두리)
- `ellipse` — POI 마커, 반경 원
- `line` — 지하철 노선 폴리라인 세그먼트, 구분선
- `text` — 모든 텍스트 (폰트 크기/굵기/색/정렬/자간)
- `table` — 분양 현황 표 (헤더 스타일, 행 데이터)
- `chart` — 평당가 비교 막대 차트 (pptxgenjs 네이티브 차트 ↔ HTML은 동일 데이터로 막대 렌더). 유일한 예외 요소: PowerPoint 차트 렌더러와 HTML 막대는 축·간격이 미세하게 다를 수 있다. 데이터·색·순서 일치만 보장한다.

**디자인 제약**: PPT로 표현 가능한 부분집합만 사용한다 — 투명도 있는 단색 채움, 그림자, 둥근 모서리, 실선/점선. CSS 그라데이션·backdrop-blur 등 PPT로 옮길 수 없는 효과는 미리보기에도 쓰지 않는다.

## 디자인 개선 (풀블리드 비주얼형)

슬라이드 구성은 현행 유지: 표지 / 입지 현황 종합 / 교통 / 교육 / 자연 / 분양 현황 / 종합 시사점 (7장).

- **타이포그래피 계층**: 슬라이드 번호(01~07) + 섹션 라벨(SITE ANALYSIS) + 대제목 3단 계층. 크기 스케일과 자간 통일. 폰트는 Noto Sans KR 유지.
- **KPI 칩**: 각 분석 슬라이드 헤더 아래 핵심 지표 칩 2~3개 (예: "지하철 4개소", "최근접 800m"). rect+text 조합.
- **패널 카드**: 좌측 데이터 패널을 얇은 액센트 바 + 정돈된 여백의 카드로 재설계. 흰색 배경 투명도와 그림자 값 조정.
- **분양 슬라이드**: 표 스타일 개선(줄무늬 행, 정렬) + 평당가 비교 네이티브 막대 차트 추가.
- **표지**: 다크 스크림(단색+투명도) 위 대형 타이틀, 지표 요약 라인, 액센트 바.
- **범례·푸터**: 크기·정렬 정돈, 출처 표기 유지.

## 오류 처리

- 지도 미준비/캡처 실패: `baseMapImage=""` 허용 — 빌더가 플레이스홀더 rect로 대체하고 슬라이드에 경고 배지 요소를 추가.
- POI 0건 카테고리: 해당 슬라이드는 생성하되 "반경 내 해당 시설 없음" 안내 텍스트. 미리보기에서 사용자가 제외 선택 가능.
- pptxgenjs 생성 실패: 모달 안에 오류 메시지 표시, 모달은 유지 (재시도 가능).

## 테스트·검증

1. `npm run build` + lint 통과.
2. 헤드리스 브라우저로 미리보기 모달 QA: 모달 열림, 썸네일 7장, 선택 토글, 슬라이드 전환.
3. 생성된 .pptx의 내부 XML(zip)을 스크립트로 검사 — 텍스트/도형/표/차트가 네이티브 요소로 존재하는지, 이미지가 슬라이드당 1장(베이스맵)뿐인지 확인.
4. 미리보기 HTML과 PPT 스크린샷 육안 대조 (주요 슬라이드 2~3장).

## 범위 외 (YAGNI)

- 미리보기 내 텍스트/레이아웃 편집
- 슬라이드 순서 변경, 템플릿 테마 선택
- PDF 내보내기
