# 보고서 모드 B안(떠 있는 패널) 설계

- 날짜: 2026-10-20
- 시안: https://claude.ai/artifact/BC55sQupgmp3qaWyoRkQQX — 둘째 줄 `B 다듬기 ①–④`, 규칙 보드, 셋째 줄 `⑤ 지도 편집 중`, `⑥ 페이지 끌어 옮기는 중`
- 사용자 결정 (2026-10-20):
  - 3안 중 **B 떠 있는 패널**을 채택했다.
  - 지도 조절 막대는 항상 띄우지 않는다.
  - 방향키는 페이지 이동, 순서 변경은 끌어 놓기로 한다.
  - 지도는 두 번 눌러 바로 마우스로 조작한다.
  - 사용자가 "진행해"로 이 설계와 다듬은 시안을 승인했다.
- 상위 문서: `docs/superpowers/specs/2026-10-19-report-mode-design.md`(보고서 모드 설계). 이 문서는 그 §2-2 편집 화면 배치와 §4 지도 프레임 편집의 조작 방식만 바꾼다. 나머지는 그대로다.

## 1. 의도

1440×900에서 슬라이드는 지금 화면의 25%(762×429)다. 이것을 73%(1294×728)로 키운다. 지금은 레일 76 + 서랍 312 + 레이아웃 칸 216, 합해서 가로 604 px가 늘 빠진다. 16:9 슬라이드는 가로가 먼저 모자라므로 이것이 주원인이다.

## 2. 화면 배치

1. **머리 줄은 1줄(56 px)이다.**
   - 앱 머리 줄(`page.tsx` topbar)에 보고서 동작을 넣는다: 되돌리기, 다시 실행, 판형, 발표, 내보내기.
   - 보고서 모드가 따로 그리던 머리 줄(눈썹 글·h1·저장 상태)은 없앤다. 주소와 저장은 앱 머리 줄에 이미 있다.
   - 모드 탭의 이름은 `보고서` + 쪽수 배지로 바꾼다(`보고서 · n쪽` 아님).
2. **무대**: 슬라이드는 남은 영역 전체에 맞춰 놓인다(contain). 떠 있는 요소가 차지하는 곳을 뺀 영역에 맞추고, 슬라이드를 가리지 않는다.
3. **떠 있는 요소** — 모두 같은 카드 모양이다(모서리 12, 테두리 1, 그림자 1벌).
   - **도구 막대**: 왼쪽 위에 둔다. 너비 56, 버튼 48×52이고, 버튼은 페이지 / 타일 / 글상자 / 테마다.
   - **서랍**: 도구 막대 오른쪽에 붙는다. 너비 320이고 열려 있는 동안 무대 왼쪽 여백이 늘어난다.
   - **페이지 줄(dock)**: 아래 가운데에 둔다. 왼쪽부터 레이아웃 메뉴 버튼, 발표 메모 버튼, 썸네일(88×50, 번호 배지), `+`, 접기 순서다.
   - **지도 설정 카드**: 오른쪽에 둔다. 너비 296이고 열려 있는 동안 무대 오른쪽 여백이 늘어난다.
4. **오른쪽 레이아웃 칸과 늘 보이던 발표 메모 칸은 없앤다.**
   - 레이아웃은 페이지 줄의 메뉴로 고른다.
   - 메모는 페이지 줄 버튼을 누르면 팝오버로 연다. 메모가 있으면 버튼에 점을 표시한다.
5. **390 px**: 서랍과 설정 카드는 지금처럼 아래 시트로 연다(포커스 가둠·닫기 유지). 도구 막대는 위쪽 가로줄이 되고, 페이지 줄은 가로 스크롤한다.

## 3. 지도 조작

| 동작 | 결과 |
|---|---|
| 한 번 누르기 | 지도를 선택한다. 그때만 **지도 막대**가 슬라이드 아래쪽에 나타난다. |
| 두 번 누르기, 또는 지도에 포커스가 있을 때 Enter | **지도 편집**을 시작한다. 끌면 이동, 휠은 커서 위치 기준 확대·축소. |
| 편집 중 두 번 누르기 | 누른 위치를 기준으로 한 단계(+0.5) 확대한다. |
| 편집 중 키보드 | 방향키로 이동, `+`/`=`로 확대, `-`로 축소한다(단계 0.25, 지금 막대 버튼과 같음). |
| Esc · 지도 바깥 누르기 · `완료` | 편집을 끝낸다. |
| `지도 위치 고정` 켜짐 | 두 번 눌러도 Enter를 눌러도 편집에 들어가지 않는다. 대신 자물쇠 버튼을 600 ms 강조한다. |

- **지도 막대는 슬라이드 위에 띄우지 않는다** (2026-10-20 Judge 결정, 사용자 취향 "어떤 오버레이도 지도를 가리지 않는다"(강한 선호 10회)·실수 기록 #1). 지도를 선택한 동안 페이지 줄 왼쪽 묶음(레이아웃·메모 자리)이 지도 묶음으로 바뀐다. 처음 한 번의 "두 번 눌러 지도 편집" 안내도 이 묶음 안에 둔다. 시안 ②③⑤의 슬라이드 위 막대는 이 결정으로 대체된다.
- **지도 묶음** (선택한 동안만 보임):
  - 선택 상태: 축척 −, `1:2,500`, 축척 +, 대지 맞춤, 고정, 설정.
  - 편집 상태: 축척 −, 축척 값, 축척 +, `완료 Esc`.
  - `이동` 버튼은 없앤다.
- **편집하는 동안**:
  - 제목·요약·범례 패널은 투명도 .35로 흐려지고 누를 수 없다.
  - 커서는 grab이고, 끄는 동안 grabbing이다.
  - 슬라이드 테두리는 3 px 파랑에 6 px 연한 테두리를 더한다.
- **지도를 선택해도 설정 카드는 자동으로 열리지 않는다.** 설정 카드는 막대의 `설정` 버튼으로만 연다.
- **Esc를 누를 때마다 한 단계씩 물러난다:** 편집 끝 → 설정 카드 닫기 → 선택 해제.
- **"두 번 눌러 지도 편집" 안내**:
  - 지도를 처음 선택했을 때 한 번만 보인다.
  - 편집을 한 번 시작하거나 ×를 누르면 다시 보이지 않는다. 브라우저 저장소 키는 `v2.report.mapEditHint`, 값은 `"dismissed"`다.
  - 저장소를 쓸 수 없으면 세션마다 다시 보인다.

## 4. 페이지 줄 조작

- **Tab 순서**: 페이지 줄은 Tab 한 칸이다(roving tabindex). 선택한 썸네일만 `tabIndex=0`이다.
- **←/→**: 이전·다음 썸네일로 가서 바로 선택한다. Home/End는 첫 썸네일·마지막 썸네일이다.
  - 이어지는 장(출처 +n쪽)도 썸네일 한 칸으로 친다.
- **PageUp/PageDown**: 무대 어디서든 이전·다음 썸네일로 간다.
  - 입력 중(`input`·`textarea`·`select`·contentEditable)이거나 지도 편집 중이면 동작하지 않는다.
- **순서 변경은 끌어 놓기가 기본이다.**
  - 놓일 자리에 3 px 파란 세로 막대를 보인다. 위치는 썸네일 가운데를 기준으로 앞/뒤를 정한다.
  - 끄는 썸네일은 투명도 .35로 흐린다.
  - 페이지 줄 끝 48 px 안에 들어가면 자동으로 스크롤한다.
- **끌기를 대신할 방법**(상위 사양 §4 "끌기로만 할 수 있는 조작" 금지):
  - Ctrl(⌘)+Shift+←/→로 한 칸씩 옮긴다.
  - ⋯ 메뉴의 `앞으로`·`뒤로`는 그대로 둔다.
- **옮긴 뒤에는** 되돌리기 토스트를 띄운다. 문구는 `{원래 쪽}쪽을 {새 쪽}쪽 뒤로 옮겼습니다` 또는 `…쪽 앞으로 옮겼습니다`다.

## 5. 글자·간격·문구

- **글자 크기는 5단계만 쓴다:**

  | 크기 | 쓰는 곳 |
  |---|---|
  | 20 | Do Hyeon. 로고·화면 제목 |
  | 16 | 빈 화면 안내 제목 |
  | 14 | 카드 제목 |
  | 13 | 기본 |
  | 12 | 보조 |

  - 12 px 미만은 쓰지 않는다.
  - 대상은 보고서 모드의 편집기 겉면(`report-mode.module.css`)이다. 슬라이드 표면(`slide-surface.module.css`)은 내보내기 결과물이므로 바꾸지 않는다.
- **굵기**는 400·500·700만 쓴다. 700은 제목과 선택된 것에만 쓴다.
- **간격**은 4 / 8 / 12 / 16 / 20 / 24 단계로 쓴다. 카드 안에 테두리 상자를 또 두지 않는다.
- **줄바꿈**:
  - 편집기 겉면 전체에 `word-break: keep-all`을 준다.
  - 목록 행은 한 줄에 말줄임으로 쓰고, 전체 이름은 `aria-label`·`title`로 준다.
  - 버튼 글자는 줄바꿈하지 않는다.
- **없애는 설명 문장** (같은 내용을 상태로 보여 준다):
  - `지도를 끌어 옮기고 휠로 확대합니다 · Esc 또는 바깥을 누르면 끝납니다`
  - `잠금 해제 후 이동 가능` / `지도가 잠겨 있어 드래그·축척·이동 입력은 무시됩니다. 판형과 레이아웃만 바꿀 수 있습니다.`
  - `1:500부터 1:50,000까지 입력합니다` → 범위를 벗어날 때만 오류로 보인다.
  - `발표 미리보기와 PPT 발표자 메모에 저장됩니다.`
  - `지도 위치와 확대는 그대로 두고 배치만 바꿉니다.`
  - 페이지 종류 카드의 설명 줄 5개
  - 서랍 눈썹 글(`보고서 구성`, `요소 추가`)
  - `비교할 타일을 2개 이상, 선택한 칸 수 이내로 고르세요.` → 만들기 버튼에 `n/칸 수 선택`을 보인다.
- **움직임**:
  - 카드·막대가 나타날 때: 180 ms, `cubic-bezier(.23,1,.32,1)`, 8 px 이동과 투명도 변화.
  - 사라질 때: 120 ms.
  - 키보드 조작에는 애니메이션을 넣지 않는다.
  - `prefers-reduced-motion`에서는 투명도 변화만 남긴다.
  - 슬라이드 크기가 바뀔 때는 애니메이션하지 않는다.

## 6. 비목표

- 무대 확대·축소(화면 맞춤 %)는 넣지 않는다. 슬라이드는 항상 맞춤이다.
- 내보내기 패널의 디자인은 이번에 고치지 않는다.
- 슬라이드 표면·PPT 출력은 바꾸지 않는다.
