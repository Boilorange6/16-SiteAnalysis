# P1 지도 라벨 — 대지에서 가까운 순 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 11개 지도 타일의 자동 라벨을 「대지에서 가까운 순」으로 바꾸고(B), 이름 없는 공동주택에 같은 필지 단지명·승인일을 라벨용으로 채운다(A-1). 화면·PNG·PDF·PPT가 같은 라벨을 그린다.

**Architecture:** 엔진은 「누가 라벨 대상인가」만 정한다(`labelPriority` 2 + 상세 줄, 공용 `distanceToGeometryM`·`nearestPerGroup`·`nearestN`). 같은 등급 안의 순서와 빠지는 순서는 렌더(`map-scene`)가 대지 중심까지의 화면 거리로 정한다. 그래서 makeTile 출력 순서는 그대로이고, 리비전은 엔진 규칙이 바뀐 11타일에만 오른다. 이름 없는 대상은 엔진이 낸 용도 이름(`unnamedTitle`)을 렌더가 보통 굵기 제목으로 쓴다. A-1 보충은 `BuildingRow`의 라벨 전용 필드라 `hit.name`·장면·D02·D29는 움직이지 않는다.

**Tech Stack:** Next.js 15 · TypeScript · zod · React SVG · pptxgenjs · better-sqlite3 · 테스트 `src/scripts/v2/test-v2-*.mjs`(`npx tsx`)

**Spec:** `docs/superpowers/specs/2026-11-03-labels-map-expression-design.md`(확정 2026-11-03). 이 계획은 §2-1 A-1과 「A-1 규칙」, §2-2 B, §3 P1 행, §3-2, §4-1과 그 아래 Judge 판정 1~10을 구현한다. 실행자는 spec과 이 계획을 함께 읽는다.
