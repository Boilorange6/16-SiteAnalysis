# 지도 라벨·지도 표현·자료 보강 P5 — D11 법규 체크리스트(E3) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** D11을 「대지에 걸린 규제 체크리스트」로 바꾼다. 대지에 걸림(포함·저촉)·접함·반경에만을 나누고, 구역마다 세부 값을 법정 상한·조례·계획 세 층으로 섞지 않고 보인다. 도판은 Q11 b(지도 + 오른쪽 열 체크리스트 표)이며 시안 승인 뒤에 그린다.

**Architecture:** 걸림은 외부 API가 아니라 적재된 면 도형과 대지 도형의 교차로 엔진이 판정한다(같은 판 데이터면 같은 답 → 캐시 키에 따로 섞을 것이 없다). 용도지구 9종은 토지이음 도시계획 SHP(data.go.kr 15047831, 공공누리 제1유형)에서 새 kind `use_district`로 reference에 적재한다. 용도지역·구역·정비구역은 이미 적재된 `zoning_area`·`district_area`·`maintenance_zone`을 쓴다. 법정 상한(시행령 제84·85조)과 서울 조례(제44·48조)는 코드의 정적 표이고, 표가 바뀌면 D11 리비전을 올린다. 체크리스트 행은 `presentation.checklist`에 실리고, 화면·PPT는 공용 표 모델 하나를 그린다.

**Tech Stack:** TypeScript · zod(`tile-result.ts`) · @turf/turf 7.3.5(`intersect`) · better-sqlite3 · React SVG · pptxgenjs · 테스트 `src/scripts/v2/test-v2-*.mjs`(`npx tsx`)

**Spec:** `docs/superpowers/specs/2026-11-03-labels-map-expression-design.md` §2-5 E3와 「E3 세부 값」 문단(Ruling 44), §3 P5 행, §3-1 E, §3-2 E 행, §4-1 Q11 b. **사용자 결정(2026-11-05)이 spec보다 우선한다:** vault `10-Projects/16-SiteAnalysis/Decisions/2026-11-05 P4·P5 원천은 VWorld 다운로드 CC BY와 토지이음 SHP.md` ③, `Decisions/2026-11-04 VWorld 허가 없음 정정과 API 저장 금지.md`, `Decisions/2026-11-05 용도지역·공시지가 원천을 data.go.kr 제한 없음 파일로 교체.md`. 그래서 spec E3의 `getLandUseAttr` 저장 경로·dsId 24 용도지구 파일·S04식 upstream 해시는 쓰지 않는다. 근거 조사: `.superpowers/sdd/2026-10-30-report-page-layout/zone-detail-research.md`(세부 값·법령 표), `next-plan-inv-sources.md` 질문 3, `.superpowers/sdd/2026-11-05-p4p5-license/report.md`. 실행자는 spec·결정 노트·이 계획을 함께 읽는다. file:line은 HEAD `946d9138`(브랜치 `v2-cartography`) 기준이다.

## Review Focus

1. **대지 경계가 없거나 여러 필지인 대지.** 좌표만으로 만든 분석(예: `0b5ba3aa`)은 걸림을 판정하지 않고 모든 행을 「반경에만」으로 두며 한계를 단다. 여러 필지 대지는 `ctx.input.site.geometry`(필지 합친 도형) 하나로 판정한다. → Task 5 Step 1 ⑥⑦
2. **경계가 대지 경계와 거의 겹치는 구역(조각 면).** 용도지역 경계는 필지 경계를 따르지만 원천 간 0.1~1 m 어긋남이 있다. 아주 작은 교차를 「저촉」으로, 맞닿은 이웃 지역을 「포함」으로 오판하면 안 된다. → Task 5 Step 1 ②③, Task 7 허용치 조정
3. **서울 밖 대지.** 조례 칸은 `해당 지자체 조례 확인`, 법정 상한만 숫자, 서울도심 단서 없음. → Task 5 Step 1 ⑤
4. **계획 우선 구역이 걸렸는데 조례값이 적용값처럼 보인다.** 지구단위계획구역·정비구역·개발제한구역이 포함·저촉이면 용도지역 행의 조례 칸 앞에 `(참고)`가 붙고 계획 칸이 `계획이 우선 — 해당 계획·담당 부서 확인`이다. → Task 5 Step 1 ④
5. **옛 저장 분석.** `checklist`가 없는 옛 D11 결과를 열어도 화면·PPT가 깨지지 않고 지금 D11 모양으로 그린다. → Task 6 Step 1 ③

- **걸림은 도형 교차로 판정한다.** spec E3는 `getLandUseAttr`(포함·저촉·접함)를 뼈대로 했으나 오픈API 저장 금지(2026-11-04)로 쓸 수 없다. 대지 도형과 적재된 면의 교차는 같은 판에서 늘 같은 답이라, S04식 upstream 해시(spec)가 필요 없다. 대가: 개별법 규제(대공방어협조구역·과밀억제권역·토지거래허가구역·가로구역별 최고높이 등)는 도형이 없어 빠진다 → 열린 질문 1(data.go.kr 15045900).
- **판정 기준(이 계획의 제안, Task 7에서 토지이음 화면과 맞춰 조정):** 교차 면적이 `max(1 ㎡, 대지 면적 × 0.5 %)` 이하면 교차 없음으로 본다. 교차 ≥ 대지 면적 × 99.5 %면 「포함」, 그 사이면 「저촉」, 교차가 없고 대지 경계와 1 m 안이면 「접함」, 그 밖에 반경 원과 겹치면 「반경」. 토지이음의 「저촉」은 법령상 다른 뜻도 쓰지만, 이 표에서는 「일부 걸침」으로 쓰고 범례에 뜻을 적는다(시안에서 확정).
- **용도지구는 새 kind `use_district`, 원천 id는 `eum_use_district`로 적재한다.** `district_area`나 `district_` 접두로 넣으면 지금 D11 엔진(`d11/engine.ts:7·20-26·121`)이 게시 즉시 새 면과 원천을 읽어, 운영 새 분석의 D11이 스타일 없는 레이어로 바뀐다. 새 kind는 Task 5가 명시적으로 읽는다.
- **토지이음 SHP에서 용도지구 9종만 적재한다.** 용도지역·구역이 함께 있어도 넣지 않는다(교체 판의 `zoning_area`·`district_area`와 중복). 9종은 국토계획법 제37조(복합용도지구 포함, 조사 report.md).
- **고도지구 높이:** SHP에 높이 필드나 비고 문구가 있으면 원문을 그대로 `heightText`로 보존하고 계획 칸에 `<원문>(원천 비고)`로 보인다(숫자만 뽑아 바꾸지 않는다 — 「16m 이하(완화시 20m 이하)」 같은 꼴을 지킨다). 없으면 계획 칸은 `토지이음에서 확인`(사용자 결정). 다른 용도지구도 값이 없으면 같은 문구를 쓴다(결정을 같은 뜻으로 넓힌 것 — 열린 질문 5).
- **서울도심 단서:** `getLandUseAttr` `ZA0014`를 쓸 수 없어 판정 원천이 없다. 상업지역 조례 칸은 토지이음 표기와 같은 꼴로 `800%(서울도심 600%)`처럼 둘 다 적는다(열린 질문 2).
- **2종일반주거 층수:** 적재된 용도지역 비고(`zoning_area.properties.remark`, 조사 §2 「서울 2종 7층이하 1,306개」)에 `/(\d+)\s*층\s*이하/`가 있으면 조례 칸에 `· N층 이하(원천 비고)`를 붙인다(조사 3-2 B). 이 비고는 교체 판(15148355)에서 같은 필드인지 원천 교체 Task 1이 확인한다.
- **정적 표의 원천 표기:** 적재 release가 없으므로 D10 `ngii_air@연도`처럼 엔진이 런타임 `SourceRef`를 만든다(`sourceId` `law_zoning_limits`·`seoul_zoning_ordinance`). 표가 바뀌면 D11 리비전을 올린다(조사 3-3 「조례 표 버전도 키에」를 리비전으로 대신).
- **행위제한(15058410)은 이번 범위 밖**(spec 「2차」).
- **정비구역 계획값:** `seoul_plan_zone` 개요(계획 용적률 등, 공공누리 제4유형)는 보이지 않고 이름과 `계획이 우선` 문구만 둔다(열린 질문 6).
