# v2 — 지도 몰입형 타일 디자인 (보드 · 펼침 · 보고서)

**사용자 요구(2026-09-30):** "지도 몰입형 디자인을 각 타일에 구현. 지도가 크게 표시되고 각 요소를 지도에 표시. 지도 몰입형이 불가능한 타일은 그 타일만의 스타일을 확립하되, 모든 타일은 통일성 있는 스타일을 가진다."

현재 문제: 카드 안에 작은 지도 + 아래 텍스트 블록, PPT는 지도 60% + 텍스트 40% — 텍스트 중심으로 보인다.

## 핵심 원칙

1. **지도(또는 주 시각물)가 타일 전체를 채운다(full-bleed).** 카드·펼침·슬라이드 모두 가장자리까지 지도. 흰 텍스트 영역을 따로 두지 않는다.
2. **정보는 지도 위에 떠 있는 "오버레이 칩/카드"로만 얹는다.** 모든 타일이 같은 위치 문법을 쓴다(아래 표). 오버레이는 반투명 흰 판(`rgba(255,255,255,.86)` + `backdrop-filter: blur(8px)` + 1px `rgba(21,23,28,.08)` 테두리 + radius 12), 항공 배경에서는 같은 판이 그대로 가독성을 보장한다.
3. **값은 지도 위 요소 자체에 붙인다.** 최근접 거리, 강조 대상 이름, 세대수 등은 해당 점 옆 라벨로. 표로 반복하지 않는다(표는 펼침 패널에서만).
4. **지도 불가 타일도 같은 문법:** 주 시각물(차트·도판·3D 장면·상태 화면)이 타일 전체를 채우고 같은 자리에 같은 오버레이.
5. **통일성:** 같은 radius(18), 같은 칩 스타일, 같은 글꼴(큰 숫자 Do Hyeon, 나머지 Noto Sans KR), 같은 여백(오버레이 가장자리 12px, 카드), 같은 색 점(타일 색), 같은 출처 띠.

## 오버레이 위치 문법 (카드 · 펼침 · 슬라이드 공통)

| 자리 | 내용 |
|---|---|
| 왼쪽 위 | **제목 칩**: 타일 색 점 + 타일명 (+ 종류 배지 `분석/도판/시뮬레이션`은 작게) |
| 오른쪽 위 | **보고서 칩**(체크, 카드·펼침만) · 그 아래 북쪽 표시(작게) |
| 왼쪽 아래 | **핵심 값 카드**: 큰 숫자 + 단위 + 한 줄 라벨, 그 아래 상태 배지 최대 2개(나머지는 "+n") |
| 오른쪽 아래 | 축척 막대 |
| 맨 아래 가장자리 | **출처 띠**: 반투명 얇은 띠 한 줄 — `출처·기준일 · © VWorld(국토교통부)`, 넘치면 말줄임 |
| 지도 위 | 반경 원, 500m 보조 원, 대지 표시, 타일 레이어 점·원·선, 강조 대상 라벨(흰 할로) |

범례는 카드에서는 숨기고(색 의미는 강조 라벨로 전달), 펼침·슬라이드에서는 왼쪽 위 제목 칩 아래 작은 범례 판.

## 표면별 구성

### 보드 카드
- 카드 전체가 지도(높이: 기본 280px, 2칸 타일은 같은 높이로 가로만 넓게). 대지 요약(2×2)은 보드에서 가장 큰 지도.
- 판단 문장은 카드에 넣지 않는다(펼침·슬라이드에서). 대신 핵심 값 카드 라벨에 한 줄 사실.
- "펼치기"는 카드 전체 클릭(키보드: Enter) + 오른쪽 위 작은 ↗ 아이콘.
- 대지 요약 카드: 지도 전면 + 왼쪽 위 큰 주소 판(주소·면적·용도지역·반경 칩, 사실 3줄) + 왼쪽 아래 자료 기준일·불완전 배지.

### 펼침(상세)
- 화면 거의 전체(가장자리 24px)를 지도로. 지도는 이 크기에서 다시 그려 해상도 유지.
- 오른쪽에 떠 있는 **정보 패널**(폭 360px, 같은 오버레이 판): 제목·핵심 값·판단 문장(사실→의미→확인할 것)·지표 표·배지(note 포함)·출처·보고서 포함 체크.
- 왼쪽 위 제목 칩+범례, 왼쪽 아래 축척, 위쪽 가운데 배경 전환(일반/지도/항공)과 닫기.
- 모바일(≤520px): 지도 전면 + 아래에서 올라오는 패널(시트, 절반 높이, 끌어올리기 대신 "더 보기" 버튼으로 확장).

### 보고서 슬라이드(16:9)
- 슬라이드 전체가 지도 이미지(가장자리까지).
- 왼쪽 위: 제목 판(타일 번호·타일명·종류). 오른쪽: 떠 있는 정보 판(폭 약 32%, 위아래 여백 두고) — 핵심 값, 판단 문장, 지표 최대 5줄, 배지. 왼쪽 아래: 범례 판. 맨 아래: 출처 띠 + 쪽 번호.
- 표지: 대지 요약 지도 전면 + 왼쪽 큰 제목 판(주소·반경·분석일·자료 기준일 범위) + 오른쪽 타일 목록 판(타일별 한 줄).
- 출처 장: 지도 없이 같은 스타일의 판 한 장(배경은 흐린 대지 지도).
- 지도 이미지는 슬라이드 비율(1920×1080) 그대로 래스터화해 오버레이는 pptx 도형·텍스트로 얹는다(편집 가능). 판 배경은 흰색 86% 투명도.

## 지도 불가 타일의 고유 스타일 (같은 문법)

| 타일 | 전면 시각물 |
|---|---|
| A07 매매 실거래 | 반경 지도 위 거래 위치 원(가격 분위 색, 거래 수 크기)이 기본 = 지도 몰입. 뒤집기(구성비 면)에서 월별 ㎡당 중앙값 차트가 전면 |
| A11 인구·가구 | 반경 지도 위 격자(1km 격자 인구) 채색 = 지도 몰입 |
| A12 토지·용도지역 | 용도지역 채색 지도 = 지도 몰입 |
| D04 준공 연대 등 도판 | 건물 도형 채색 지도(건물 데이터 적재 전에는 점) = 지도 몰입. 뒤집은 면(구성비)은 **전면 막대/도넛 차트**: 연한 타일색 바탕(타일 색 6%) 위에 차트가 가득, 같은 오버레이 위치 |
| S02 일조 · S01 3D · S03 바람 | 3D/평면 장면이 전면(지금은 미제공 → 상태 화면) |
| 미제공·실패·자료 없음 | **상태 화면**: 대지 지도를 흐리게(흑백 + 밝기↑ + blur 2px) 전면에 깔고, 가운데 상태 판("다음 단계에서 제공" / "계산 실패 · 이 타일 다시 계산" / "자료 없음"), 제목 칩·출처 띠는 그대로. 빈 흰 카드 금지 |

이번 구현 범위: 위 문법을 **모든 현 타일**에 적용(A01·A02·A03·A04·A05·A06은 지도 몰입, D04는 지도 점 + 뒤집은 면 전면 차트, 나머지 미제공 타일은 상태 화면), 카드·펼침·슬라이드 3면 모두. A07·A11·A12의 데이터 기반 레이어는 해당 데이터 연결 때 같은 문법으로.

## 구현 메모

- 공통 컴포넌트: `ImmersiveTile`(frame: card|detail) = `MapFigure`(chrome 없는 모드: 범례·축척·북쪽을 figure 밖 오버레이로 뺄 수 있게 옵션화) + 오버레이 슬롯. 슬라이드는 `render-pptx.ts`에서 같은 위치 규칙을 상수로 공유(`src/lib/v2/ui/overlay-layout.ts`에 위치·크기 토큰).
- `MapFigure`는 컨테이너 비율에 맞게 반경 원이 짧은 변의 80%가 되도록(카드는 가로가 길다) — 기존 프레이밍 규칙 유지.
- 강조 라벨 충돌: 간단한 겹침 회피(아래→위→오른쪽 순으로 밀기, 그래도 겹치면 생략하고 펼침에서 표시).
- 성능: 보드 12장 × 지도 — 타일 이미지 캐시(프록시) 사용, 화면 밖 카드는 `IntersectionObserver`로 늦게 그린다.
- 접근성: 오버레이 텍스트 대비 4.5:1 이상(항공 포함), 카드 전체 클릭 + 키보드, 상세 대화상자 초점 관리 유지.
