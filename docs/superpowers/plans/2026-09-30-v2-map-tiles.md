# v2 — 지도 중심 타일 (분석 타일 = 지도 + 핵심 지표 + 한 줄 판단)

**목표:** 분석 타일 5종(A01·A03·A04·A05·A06)과 대지 요약 칸을 지도가 주인공인 화면으로 바꾸고, 같은 그림을 보고서 슬라이드에도 넣는다. 스펙 §5 "분석: 지도 + 핵심 지표 + 한 줄 판단", 시안 `docs/design/alt4/A4-*.png`.

**브랜치:** `v2-map` (← `v2-p1b`). 판정 Claude, 구현 Sonnet.

## 결정

1. **지도 그림은 직접 그리는 SVG 하나(`MapFigure`)로 통일한다.** 카드(작게)·펼침(크게)·PPT(이미지) 모두 같은 컴포넌트/같은 입력. Leaflet 인터랙션은 이번에 쓰지 않는다(보고서 우선, 결정적 출력).
   - 투영: Web Mercator. 중심 = 분석 중심, 줌은 반경 원 지름이 그림 높이의 80%가 되게 계산(v1 `map-view.tsx`의 PPT 프레이밍 규칙과 같음).
   - 배경: CARTO light(`https://{s}.basemaps.cartocdn.com/light_all/{z}/{x}/{y}{r}.png`, v1이 이미 쓰고 CSP 허용됨)를 SVG `<image>` 타일로 깐다. 저작권 표기 "© OpenStreetMap contributors © CARTO"를 그림 오른쪽 아래에 작게. 배경을 못 불러와도 그림은 그려진다(배경 없이 흰 바탕 + 격자).
   - 항공사진(VWorld)은 이번 범위 밖(API 키 설정 필요) — `basemap` 옵션 자리만 둔다.
2. **엔진이 표시용 지물을 돌려준다.** `TileResult.presentation`에 선택 필드 `features`를 추가한다(`tile-result.ts` zod, 기존 결과와 호환 — 없으면 빈 배열):
   ```ts
   features?: { layer: string; lng: number; lat: number; weight?: number | null; label?: string | null; highlight?: boolean }[]
   featuresTotal?: number   // 잘리기 전 전체 개수
   ```
   - 상한 3,000개. 넘으면 결정적으로 고르게 추리고(`feature_id` 순 등간격), 화면·슬라이드에 "표시 3,000 / 전체 n"을 적는다. 최근접 등 `highlight` 지물은 항상 포함.
   - 좌표는 WGS84(`FeatureHit.geometry`는 EPSG:5179 → 기존 `crs.ts`로 역변환).
   - `presentation.legend`는 레이어별 라벨·색을 채운다(색은 화면 쪽 `tile-catalog`에서 레이어 id로 정한다).
3. **타일별 그림**

| 타일 | 레이어 | 표현 |
|---|---|---|
| 대지 요약 | 대지·반경 | 배경 지도 + 대지 표시(검은 사각) + 반경 원 + 500m 간격 보조 원(점선) + 축척 막대·북쪽 표시 |
| A01 | `bus_stop`, `bus_nearest` | 정류장 작은 점, 최근접 정류장 강조 + 중심에서 직선 점선과 "직선 205m" 라벨. 철도 미적재 문구를 그림 안 범례에 |
| A03 | `store:<그룹>` | 기초 4군(식료품·의료/약국·음식카페·생활서비스)은 색 점, 기타는 옅은 회색 점. 군별 최근접 1곳 강조 |
| A04 | `park`, `park_nearest` | 원 크기 = √원천 면적(대표점 기준, **경계 아님** — 범례에 "대표점·원천 면적 비례") |
| A05 | `apt`, `other_housing`, `officetel` | 원 크기 = √세대수(없으면 최소 크기, 속 빈 원), 유형별 색 |
| A06 | `applyhome`, `move_in` | 원 크기 = √세대수, 원천별 색, 라벨 = 입주·예정 월(있으면). 범례에 "원천별 표시 · 중복 가능" |

   공통: 반경 원·대지 표시·축척·북쪽·범례·출처 줄은 모든 그림에 있다. 텍스트는 겹치면 생략(라벨은 강조 지물만).
4. **레이아웃**
   - 카드: 위쪽에 그림(가로 전체, 높이 ~180px), 아래 큰 숫자 1개 + 배지 + 한 줄 판단 + 출처. 기존 코드 원(A01 등 동그라미)은 그림으로 대체.
   - 대지 요약 칸: 배경 장식 원을 실제 `MapFigure`로 교체(2×2 칸 전체를 지도로, 글자는 왼쪽 위 반투명 판 위).
   - 펼침(상세): 왼쪽 그림 60%(크게), 오른쪽 지표 표·판단·배지·출처.
   - 모바일(≤520px): 카드 그림 높이 140px, 상세는 그림 위·표 아래.
5. **PPT:** 분석 타일 장 = 왼쪽 60% 지도 이미지 + 오른쪽 큰 숫자·표·판단, 아래 출처·기준일. 표지 = 대지 요약 지도 + 주소·반경. 이미지는 브라우저에서 `MapFigure` SVG를 캔버스로 래스터화(1600×1000, 배경 타일은 `crossOrigin="anonymous"`)해 `report-plan`에 넘긴다. 배경 타일이 CORS로 막히면 배경 없이 넣고 조용히 계속한다. Node 테스트(브라우저 없음)에서는 이미지 없이 자리표시 사각형이 들어가고 테스트는 그것을 허용한다.
6. **예시 데이터(고덕동 fixture)도 `features`를 갖게** 해서 로그인 없이도 지도 타일이 보이게 한다(좌표는 고덕동 주변 그럴듯한 예시, "예시 데이터" 배지 유지).

## 검증

- `npm run test:v2`, `npm run lint`, `npm run build` 통과.
- Playwright(port 3111)로 `/site/v2` 예시 보드 캡처: 1440×900 보드, 상세(A03), 모바일 390. 카드 그림에 배경 지도·점·반경 원이 실제로 보이는지 캡처를 직접 보고 확인. PPT를 내려받아 PowerPoint COM으로 표지·A01·A05 장 PNG 추출 후 확인.
- 실제 데이터 확인: `npm run v2:review`가 계속 통과하고, 개포동 12 반경 1km 결과의 A03 `featuresTotal`·표시 수를 보고.
