# v2 — 주변 단지 설명선(콜아웃) 타일 (A05, 이후 A06)

**사용자 요구(2026-09-30):** v1 "주변 분양 현황" 장(지도 몰입 + 좌우로 지시선을 빼 단지를 설명)을 개선해 주변 단지 타일로 쓴다. 승인된 개선안 그대로 구현한다.

**참고(읽기 전용):** v1 `src/lib/ppt-generator.ts` `addApartmentCalloutSlide`·`buildResidentialTableRows`(2355–2560행 부근), `src/lib/ppt-callout-layout.ts`(좌우 칸 수용량), 캡처 `.superpowers/sdd/p4api-callout2.png`(메인 저장소 루트). v1 약점: 지시선이 길고 교차, 점–표 짝이 선에만 의존, 장 나눔 기준 불명, 점이 모두 같은 크기·색.

## 규칙

1. **좌우 배정:** 대지(중심) 기준 x가 왼쪽인 단지는 왼쪽 칸, 오른쪽은 오른쪽 칸. 한쪽이 넘치면 중심선에 가장 가까운 것부터 반대쪽으로 넘긴다.
2. **무교차 쌓기:** 각 칸 안에서 점의 y 순서대로 위→아래로 쌓는다(칸 안 순서 = 점 세로 순서 ⇒ 같은 칸 지시선끼리 교차 없음). 칸 높이를 넘으면 최소 간격 유지하며 균등 재배치(순서 유지).
3. **지시선:** 점 → 짧은 수평 꺾임 → 표 안쪽 가장자리. 1px, 흰 할로 위 어두운 선(밝은 배경) / 흰 선(항공). 점과 표에 같은 **번호 원**(①②…, 번호 = 세대수 순위).
4. **점:** 크기 = √세대수(최소·최대 반지름 고정), 색 = 준공 연대(D04 팔레트 공유: 1979이하/80년대/90년대/2000년대/2010년대/2020이후/미상). 선택(펼침에서 클릭·호버) 단지는 링 강조.
5. **표(콜아웃 카드):** 이름 띠(번호 원 + 단지명, 말줄임) + 4행 고정 `세대수 / 준공(yyyy년, n년차) / 직선거리 / 층·동`. 값 없으면 "확인필요". 주차·시공사는 값이 있을 때만 5번째 행(없으면 행 생략하지 말고 4행 유지). 스타일은 몰입형 오버레이 판(`overlay-layout.ts` 토큰) 그대로.
6. **장 나누기(펼침·PPT):** 세대수 내림차순, 한 페이지 10단지(좌 5·우 5), 모든 페이지 같은 지도 범위, 제목에 "세대수 상위 1–10 / 전체 N단지".
7. **개요 페이지(첫 장):** 설명표 없이 전체 단지를 번호 점으로 + 왼쪽 아래 핵심 값 카드(단지 수·확인 세대 합계·준공 중앙값) + 범례(준공 연대 색, 크기=세대수).
8. **보드 카드:** 상위 6단지(좌 3·우 3)만 설명표. 카드가 작으면 표를 이름+세대수 2줄로 축약(규칙 동일, 행 수만 축소).
9. **펼침:** 페이지 넘김(‹ 1/5 ›), 오른쪽 정보 패널은 몰입형 규칙 유지(패널 폭만큼 콜아웃 오른쪽 칸을 안쪽으로 이동).
10. **PPT:** 개요 1장 + 페이지당 1장. 지도는 전면 이미지, 번호 원·지시선·표·제목·범례·출처 띠는 편집 가능한 pptx 도형/텍스트, 단지별로 그룹(v1처럼 `callout-<id>` 그룹 이름). 보고서 장수 계산(`reportPages`/`report-plan`)에 A05 페이지 수를 반영(타일 설정에 "설명표 페이지 수: 개요만 / 상위 10 / 전체" 선택, 기본 "상위 10" = 개요+1장).
11. **단지 없음:** 지도 유지 + 가운데 상태 판 "반경 안 확인된 단지 0 · 기준 …".
12. **데이터:** 엔진 A05 `presentation.features`에 단지별 `households`, `approvalYear`, `floorsMax`, `buildingCount`, `distanceM`, `name`, `type`을 담는다(엔진에 이미 있는 값만; 없으면 null). K-APT·건물 도형 연결은 다른 브랜치(`v2-engine2`, `v2-buildings`)가 채우므로 필드 이름을 맞춰 null 허용.
13. **A06에 재사용 가능한 구조:** 레이아웃·렌더는 `callout-layout.ts`(순수 함수)·`CalloutMap` 컴포넌트로 분리하고, 행 정의만 타일별(A06: 입주 시기/세대수/원천/중복 가능).

## 테스트 (순수 로직)

- 좌우 배정·넘침 이동, 칸 안 순서 = 점 y 순서, **모든 배치에서 같은 칸 지시선 교차 0**(무작위 200케이스 속성 테스트), 칸 넘침 시 최소 간격, 번호 = 세대수 순위, 페이지 나누기·범위 고정, "확인필요" 행, 장수 계산.
