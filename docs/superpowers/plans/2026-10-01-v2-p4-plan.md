# v2 P4 — 확장(바람·UTCI·A0 해소 원천·보행망) 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** spec §6 P4 행 — S03 바람 탐색, S04 UTCI, A0에서 풀린 원천의 D01 항공사진·D10 수목·D26 통학구역, A08 임대차, 보행망 도보시간 — 과 P3에서 이월한 항목(S02 계절 4컷, D13·D14·D24 표본점 → `MapLine`, D16 연면적 지표, A02 배정 학교)을 만든다. v1·P3 기준을 깨지 않는다: 모든 타일은 `TileResult` 계약, 분석 중 외부 호출 0(배경지도 WMTS 타일은 §3.1 예외), 내보내기는 저장된 결과에서만.

**Architecture:** S03·S04는 spec §4.4가 "S03 구현 때 정한다"고 둔 계산 위치를 **엔진(Node)** 으로 정한다(open Q1). S02·D21과 같은 방식으로 `tile_result`에 캐시하고 화면·PPT는 기존 면 지물(`presentation.polygons`) 렌더를 그대로 쓴다 — 새 UI 컴포넌트가 없다. S03은 2D D2Q9 격자 볼츠만(LBM) 평면 모형(`sim/wind.ts`), S04는 공식 UTCI 다항 근사식(`sim/utci.ts`) + 명시적 단순 복사모델(양지/그늘)이며, 입력 기상은 `weather.sqlite`에 새로 집계하는 월×시각 대표값(`weather_month_hour`)이다. D01은 이미 있는 VWorld WMTS 프록시(`src/lib/v2/tiles.ts`, `Satellite`+`Hybrid`)를 타일 결과의 `presentation.basemap`으로 고정하는 배경 전용 도판이다. D10은 항공영상 수관 추론(모델·GPU 필요) 대신 Geofabrik OSM free SHP의 landuse·natural 면(산림·과수·초지·공원)을 "녹피"로 부분 제공한다(open Q7). D26은 사용자가 확보할 학구 도형 SHP를 기존 `feature_link`(`zone_geometry` → `school_zone_geom:<공간객체ID>`)에 잇는다. 보행망은 reference `feature(road)`(OSM)에서 좌표 키로 노드를 합친 그래프에 단일 출발 Dijkstra를 돌리는 `walk-shared.ts`다. A08은 A07의 `collectTrades` 패턴으로 `property_transaction`의 전세·월세 행을 읽는다.

**Tech Stack:** TypeScript, better-sqlite3 12, @turf/turf 7.3.5(`union`·`isobands` 기존 사용), proj4, zod 4, pptxgenjs 3.12, React 19 SVG, 테스트 `node:assert/strict` + `npx tsx`. **새 npm 의존성 없음.** WebGPU·ML 모델·외부 라우팅 서비스 없음.

**Spec:** `docs/superpowers/specs/2026-09-29-site-analysis-v2-design.md` §3.1(외부 호출 예외: WMTS), §3.6(VWorld WMTS), §4.1(보행 시간은 보행망 라우팅 도입 뒤), §4.2(A02·A08), §4.3(D01·D10·D26), §4.4(S03·S04·계절 4컷·UTCI 풍속 범위), §6(P4 행), §6.2(미제공 허용 항목), §7(항공영상 권리 해소, 학구도 폴리곤 없음). 지표·범례 근거: `docs/research/2026-09-29-tile-catalog-astra.md` §A08·§S03·§S04·§4(D01·D10·D16·D26). 원천 권리: `docs/superpowers/a0/2026-09-29-a0-verification.md` #10(school_zone ⏳)·#19(osm ✅)·#21(weather ASOS ✅)·#22(vworld_wmts ✅ 해소). 이월 목록: `docs/superpowers/plans/2026-10-01-v2-p3-plan.md` "P4로 미루는 것", `docs/superpowers/plans/2026-09-30-v2-p2-spatial-plan.md` Q6·차단 항목. 충돌 시 spec을 따른다.

## Global Constraints

- 기존 앱 파일(`src/lib/server/**`, `src/app/site/**`, `deploy/**`)은 수정하지 않는다. v2는 `src/lib/v2/**`, `src/components/v2/**`, `src/app/v2/**`, `src/app/api/v2/**`, `src/scripts/v2/**`만 만진다(spec §4.6).
- **새 npm 의존성을 추가하지 않는다. `npm install`을 실행하지 않는다.** 워크트리에는 `node_modules`가 없고 메인 체크아웃 것을 쓴다.
- **데이터 빌드·외부 다운로드·API 수집을 실행하지 않는다.** `.cache/v2/data/.lock`을 buildings 빌드(pid 36488, `2026-10-01b`)가 쥐고 있고 parcels·terrain·weather가 뒤에 대기한다. 데이터 작업은 §"데이터 운영"의 명령을 **사용자/운영자**가 실행한다. 테스트는 모두 임시 디렉터리 픽스처(`engine-fixture.mjs`)로 한다. `.cache/v2/data` 아래에는 아무것도 쓰지 않는다. `.cache/v2/raw`는 읽기도 하지 않는다(픽스처만).
- PNU·법정동 코드는 문자열. 모르는 값은 `NULL`(`missing`). `value_status`는 `observed / estimated / suppressed / missing / not_applicable`.
- 거리·면적은 EPSG:5179 미터(`toUtmk`). 구간은 하한 포함·상한 제외, 마지막 구간 상한 개방. 격자형 결과는 `bandPolygons`로 밴드 면을 만들고 `areaInCircle` 교차 면적을 분자로 쓴다.
- **시뮬레이션은 탐색·근사다.** S03은 "보행 안전·구조설계·인허가·검증된 CFD 결과로 사용할 수 없다", S04는 "현장 측정·개인별 건강 위험 예측을 뜻하지 않는다"를 그대로 적는다(tile-catalog §S03·§S04). m/s·°C 절댓값을 실측처럼 쓰지 않는다. S03은 상대풍속 `U/Uref`만 지표로 낸다. UTCI 풍속은 10 m 관측값이고 적용 범위 0.5~17 m/s 밖은 **자르지 않고** 범위 밖 면적률로 낸다(spec §4.4).
- 직선거리를 도보 n분으로 환산하지 않는다. 도보 시간은 **보행망 라우팅 결과에만** 붙이고 문구에 "보행망 도보(OSM, 내부 제안 기준)"를 명시한다. 등급(좋음·보통·주의)은 spec §4.1 표대로 **직선거리**에만 매긴다.

## Review Focus

1. **시뮬레이션 수치가 실측처럼 새는 경로** — S03 지표는 `U/Uref`뿐이고 m/s 지표가 없다. S04는 `inRange === false` 셀을 `utci_out_of_range` 범주로 분리하고 중앙값 계산에서 뺀다. 풍속을 0.5로 올리거나 17로 내리는 코드가 없어야 한다. (T10·T11 테스트: `assert.ok(!metrics.some(m => m.unit === "m/s" && m.id.startsWith("urel")))`, 범위 밖 픽스처에서 `share_out_of_range_pct === 100`·`utci_median` missing)
2. **직선거리와 보행거리 혼합** — A01·A04·A02의 등급은 기존 직선 지표로만 매기고, `walk_*_min`은 보행망이 없으면 `missing`이며 라벨에 "직선"이 붙지 않는다. (T15·T7 테스트: `grades[].metricId`가 `walk_`로 시작하지 않음)
3. **배정 학교를 가까운 학교로 대신하는 경로** — D26·A02는 학구 폴리곤 ∋ 대지 중심 **그리고** `feature_link serves_zone`이 있을 때만 배정 학교를 쓴다. 학구는 있는데 연결이 없으면 `in_school_zone = 1`이되 `assigned_elem`은 `missing`. (T7 테스트)
4. **OSM 녹피를 수관 추정으로 표시하는 경로** — D10 라벨·문장·제목에 "수관"·"추정 수목"을 쓰지 않고 "OSM 녹피(토지이용)"로 적는다. 중첩 면(공원 ∩ 산림)은 합집합으로 총면적률을 내고 분류별은 "중복 가능"을 표시한다. (T6 테스트)
5. **데이터 스키마 열 추가가 옛 파일을 깨는 경로** — `property_transaction.renewal`·`weather_month_hour`는 옛 market·weather 파일에 없을 수 있다. A08·S04는 `PRAGMA table_info`/`sqlite_master`로 확인하고 없으면 `missing`·`notProvided`로 간다. (T4·T8·T11 테스트: 열 없는 픽스처)
