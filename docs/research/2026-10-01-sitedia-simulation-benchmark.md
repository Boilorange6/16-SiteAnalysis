## 2. 우리(P3 완료 시점)와의 차이

| 항목 | 우리 현재 | sitedia | 판단 |
|---|---|---|---|
| D21 일조시간 | 대지 필지만, 09~15시(최대 6시간) | 반경 전체, 하루 전체, 법정 참고 지표, 진태양시 | **우리가 크게 부족** — 도판으로서 정보량이 적다 |
| S03 바람 | 미구현(P4 계획: 엔진 2D LBM, 반경 ≤400m) | 3D LES 800m, LIC | 계획안은 범위가 좁다. 2D라도 **반경 전체**는 CPU로 충분히 가능(400×400 격자 × 2,500스텝 ≈ 4억 셀 갱신, Node 수 초) |
| S04 UTCI | 미구현(P4 계획: Ta+15°·sin고도, 바람 10m 일괄) | 바람장·그늘·수목·하늘열림 결합 | 계획안은 공간 차이가 거의 없다(햇볕/그늘 두 값). 바람장과 하늘열림을 써야 "자리끼리 비교"가 된다 |
| D10 수목 | 미구현(P4 계획: OSM 녹지 면 대체) | 항공영상 색 검출 | 색 지수(ExG 등) 임계값이면 ML·GPU가 필요 없다. VWorld 항공영상 허가 확보됨 |
| 도보권 | 미구현(P4 계획: 80m/분, 최근접 도보거리) | 80m/분 5·10분 도달 면 | 같은 기준. **도달 면(등시선)**을 도판으로 추가 |
| 개방감(하늘열림) | 없음(스펙에 없음) | 23번 도판 | UTCI에 어차피 필요 → 같이 만든다 |
| 3D 분해 다이어그램 | 없음 | 6층 분해 | 보고서 표지·컨셉 장에 효과적. 장면 계약이 있어 S01 그림 확장으로 가능 |
| 바람장미 | 연간 1개(ASOS 105지점, 대지 최근접 장기 관측소) | 연간+4계절(EPW) | 원자료가 시간 단위라 계절 분리는 쉽다 |
| 보고서 | 편집 가능한 PPT(스택·조판·컷) | PPT 없음 | **우리 강점 유지** |

## 3. P4 방식 결정(Judge)

| # | 결정 | 근거 |
|---|---|---|
| R1 | **D21·S02 일조를 반경 전체·하루 전체로 확장**. 진태양시, 지표 = 평균 일조·1시간 미만 %·09~15시 연속 2시간 %·08~16시 총 4시간 %. 그림자는 시각마다 건물 그림자 다각형을 격자에 칠하는 방식(셀별 광선 대신)으로 수 초 안에. 계절 4컷(하지·춘분·추분·동지)은 같은 엔진으로 | sitedia 대비 가장 큰 격차, 계산 방식만 바꾸면 비용 낮음. P3 Q6(09~15 고정)은 이 결정으로 대체 |
| R2 | **S03 바람: 엔진 2D LBM(D2Q9)을 반경 전체(≤1,000m), 4~5m 격자**로. 결과 = 풍속비 밴드 면 + 유선(MapLine). 계절 주풍향 선택은 4컷 중 하나로. 계산은 워커 스레드(성능 Q12와 함께) | 3D LES·GPU는 서버에 없음. 2D 보행층 근사로도 "건물 사이 강풍·정체" 읽기는 가능하고 한계 문구로 정직하게 표시 |
| R3 | **S04 UTCI: 바람=S03 장, 그늘=R1 그림자, 하늘열림=신규 SVF, 기온·습도·일사·전운량=ASOS 월×시 대표값**. 4계절 × 10/14/18시 | 계획안(두 값)보다 공간 정보가 생김. 입력은 이미 수집 중(ASOS에 ta·hm·icsr·dc10Tca 저장) |
| R4 | **D10 수목: VWorld 항공영상 색 지수 검출로 전환**(ExG·밝기 임계 + 작은 구멍 메우기 → 면). 결과에 "항공사진 색 기반 · 재현율 확인 필요" 표시. OSM 녹지 면은 보조 레이어 | sitedia 수준 결과를 ML 없이 낼 수 있다. 영상 디코딩에 이미지 라이브러리 필요(아래 Q-A) |
| R5 | **도보권: 5·10·15분 도달 면 도판 추가**(80m/분, OSM 보행망) | 계획의 보행망 작업에 면만 더하면 된다 |
| R6 | **개방감(SVF) 도판 추가** | R3 입력이자 독립 도판 |
| R7 | **S01 분해 다이어그램 컷 추가**(건물·도로·녹지·지형·완성) | 보고서용 효과 큼, 장면 계약 재사용 |
| R8 | **D22 바람장미 계절 4개** | 원자료 시간 단위 |
| R9 | 유지: A08 아파트 전월세, D26 학구 SHP(사용자 확보), 공부면적 제외, 지형은 **Copernicus DEM GLO-30으로 전환(P4)** | sitedia에 없거나 현재로 충분 |
