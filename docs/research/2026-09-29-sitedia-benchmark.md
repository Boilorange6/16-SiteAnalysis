## 1. 서비스 개요, 타깃 사용자, 가격/계정 모델

**한 줄 정의**: 주소(또는 지도 클릭)로 대지를 지정하면, 반경 안의 도시 현황을 원형 프레임의 "보고서용 대지분석 다이어그램" 22장으로 자동 작도하고 SVG/PNG/DXF/3D로 내보내는 도구.

- **타깃**: 건축·도시설계 실무자와 학생 (현상설계 초기 리서치, 설계 보고서/공모 제출물의 "대지분석" 장). 유료화 설문 문항이 "학생 / 실무 1~3년 / 실무 4년+"로 되어 있어 타깃이 분명함.
- **핵심 가치 제안**: "지도 캡처 → 일러스트레이터 트레이싱 → 용도별 색칠"을 한 장에 1~2시간씩 하던 반복 작업 자동화. 결과물은 "완성 그림이 아니라 편집 가능한 재료(SVG 레이어)".
- **운영**: 도시 분야 1인 개발자. 문의 admin@sitedia.app. 인앱 "의견" 플로팅 버튼으로 피드백 수집.
- **제품 철학(반복 강조)**: "없는 데이터를 지어내지 않는다 — 예쁜 거짓말보다 정직한 회색". 미상은 연회색, 높이 모르는 건물은 3D에 세우지 않음, 모든 도판 아래 출처 줄 유지. 법적 판단/인허가 근거로 쓰지 말라고 명시.

| 지형·등고선·경사도 | AWS Terrain Tiles(terrarium) | 절대표고 오차(도심 +7~10m, 최대 +54m) → 상대고만 사용, 경사 50m 평활. 국토지리정보원 5m DEM은 API 없어 미사용 |
| 항공영상·수목 | VWorld 항공영상 RGB | 촬영시기 불명, 수목 재현율 70% |
| 기상(바람장미·UTCI) | EPW/TMYx (Lawrie & Crawley, climate.onebuilding.org) | 관측소명·거리·기간 항상 표시 |
| 법령 문구 | 국가법령정보 공동활용 API(법제처) | 일조 기준 등 |
| 배경지도 | VWorld WMTS (Base) | 지도에 지하철 출구 번호까지 표시됨 |

라이선스 안내: 공공누리, OSM ODbL(도판은 해당 없음), 가로수 대장처럼 상업이용 금지 자료는 검증용으로만 사용.

## 4. UI/UX 분석

### 레이아웃
- **싱글 페이지 롱스크롤 도구**(데스크톱 폭 약 1190px 중앙 정렬, 페이지 높이 모바일 기준 약 14,800px). 랜딩과 도구가 분리되지 않음 — 첫 화면이 곧 도구.
- 위→아래 순서: 헤더(국가 토글 KR/US, 제목, 메타 지표, 로그인/회원가입) → 데이터 한계 공지 박스 → **지도(좌 약 70%) + 컨트롤 패널(우 약 30%)** → 22장 그리드(4열) → 시트 탭 01~07 → 가이드 카드 그리드 → 데이터 출처 각주 → 정책 링크 푸터. 우하단 "의견" 플로팅 버튼.
- 스크린샷: `sitedia/01-landing.png`, `sitedia/01-landing-full.png`, `sitedia/09-after-gen-top.png`

### 흐름
1. 주소 입력(Enter) → 후보 드롭다운 → 선택 시 지도 이동 + 좌표 카드("서울특별시 종로구 세종대로 175 / 37.57257, 126.97567")
2. 대지 지정 방식 선택(점/필지/구역계) → 모드별 **맥락 힌트 문구가 검색창 아래에서 바뀜**("필지를 여러 번 클릭하면 묶이고… Alt+클릭은 새로 시작")
3. 도형·반경 → "다이어그램 생성"(검정 풀폭 버튼) → 진행 카운터 → 그리드가 빈 원형 플레이스홀더에서 실제 도판으로 채워짐
4. 추가 작업(3D/시뮬/조판)은 아래 탭에서.
- 첫 방문 시 이미 **서울 명동 기본 위치 + 800m 원**이 그려져 있어 빈 화면이 없음. 22장 자리도 이름 붙은 회색 원 플레이스홀더로 미리 보여 "무엇이 나올지"가 즉시 전달됨.

### 시각 언어
- 배경 웜 오프화이트 `rgb(250,248,244)`, 잉크 검정 버튼, 포인트 컬러 붉은색(대지 표식·반경 슬라이더·공지 좌측 보더). 카드 라운드 + 얇은 보더, 그림자 거의 없음 — 건축 보드/인쇄물 같은 톤.
- 폰트: 시스템 스택(`-apple-system, Apple SD Gothic Neo, Pretendard, Segoe UI`). 수치는 모노스페이스 느낌(14,390,000동).
- 도판 캡션: 영문 대문자 자간 넓은 제목 + 한글 부제(건축 보드 관행). 원형 프레임 통일, 대지 표식은 빨간 역삼각형.
- 팔레트: 패널별 단일 강조색(고층 마젠타, 저층 보라, 높이 블루 램프, 연대 적갈색 램프, 녹지 연두), 미상은 연회색으로 일관.
- 세그먼트 컨트롤(점/필지/구역계, 원형/정사각/사각)은 검정 채움 = 선택.

### 인터랙션/상태
- 로딩: "생성 중… n/22" 텍스트 카운터 + 패널이 하나씩 채워짐. 시뮬레이션은 전용 busy 오버레이(스피너+부제), 계산 시간 사전 고지(툴팁 "약 30~60초").
- 빈 상태: "다이어그램을 만들면 여기에 3D로 나옵니다", "대지를 고르면 여기에 나옵니다" 등 각 영역에 구체 문구.
- 게이트: 잠금 아이콘 🔒 + 흐림 처리 → 클릭 시 모달 "로그인하고 계속하기 — SVG 내보내기는 로그인이 필요합니다"(**무엇 때문에 막혔는지 명시**).
- 툴팁(title) 풍부: 모든 토글에 기능·한계 설명.
- 모바일(390px): 1열로 스택, 가로 스크롤 없음, 지도 → 컨트롤 순. 별도 모바일 최적화는 없음(`sitedia/12-mobile.png`, `sitedia/12b-mobile-map.png`).

### 강점
- "주소 하나 → 즉시 결과"까지 클릭 3번. 첫 화면에서 도구가 동작 중인 상태로 시작.
- **데이터 한계를 UI 전면에 노출**(공지 박스, 미상 회색, 캡션 "50m 평활", 관측소 거리) → 전문가 신뢰 확보.
- 결과물이 "보고서에 바로 붙는" 형태(통일된 원형, 범례·출처 자동, 조판 시트).
- 콘텐츠(가이드)가 곧 SEO이자 교육.
- 서버 렌더 + 캐시로 22장이 10초 내.

### 약점
- 한 페이지에 기능이 과밀 — 스크롤이 매우 길고 하단 탭 7개는 발견성이 낮음.
- 분석 "판단"이 없음(점수·요약·해석 없음). 사용자가 22장을 직접 읽어야 함.
- 주거/투자 관점 데이터 부재(실거래가, 학교 배정, 아파트 단지, 정비사업, 계획 철도) — 순수 "도시 형태" 도구.
- 저장/프로젝트 기능 없음(결과 서버 보관 안 함).
- 도심은 미상 비율이 50~60%로 높아 용도/연대 도판의 정보량이 낮음.
- FAQ·이용안내·UI 간 정책 불일치, US 페이지 번역 누락 등 과도기 흔적.
- 검색은 Enter를 눌러야 후보가 뜸(자동완성 아님).

## 5. 랜딩 구성 분석 (#stats 포함)

- 페이지에 `id="stats"` 앵커는 없음(`/stats`는 404). "stats"는 코드상 **07 구성비 탭**(`/api/stats`, `statsExportSVG`)을 가리킴. 헤더 메타 영역(`#meta-bld`, `#meta-cov`)이 사실상의 "지표 스트립": **건물 14,390,000동 · 범위 전국 · 출력 SVG·PNG·DXF·GLB · 계정**. 규모 숫자 하나로 신뢰를 주는 방식.
- 구성 요소별:
  1. 국가 토글(KR/US 필 버튼) — hreflang 대응 별도 URL
  2. 제목 + 한 줄 가치 제안("대지를 지정하면 도시 현황을 다이어그램 22장으로 작성합니다")
  3. 메타 지표 스트립 + 계정 버튼
  4. **건물 정보 안내**(붉은 좌측 보더 공지): 실제 현장과 다를 수 있음 + 데이터 출처 링크 — 기대치 관리를 첫 화면에서
  5. 도구 본체(지도 + 컨트롤)
  6. 22장 그리드(생성 전 플레이스홀더 = 샘플 역할)
  7. 7개 고급 탭(로그인 게이트 = 업셀 쇼케이스)
  8. 가이드 카드 13개("도판이 무엇을 계산한 것이고 무엇을 계산하지 않았는가")
  9. 데이터/참고 각주(배포일, 채움률)
  10. 정책 링크 + "기본 기능은 계속 무료" 문구
- 별도 히어로 이미지·마케팅 카피·고객 로고·가격표 섹션 없음. **도구 자체가 랜딩**이며 SEO는 가이드 글이 담당(sitemap에 가이드 13편×KR/US).
- 메타 description: "주소 하나로 끝내는 보고서용 대지분석 다이어그램 22장…"

## 7. 우리 앱이 sitedia보다 나은 점 (유지할 것)

1. **판단을 준다**: 교통/교육/자연/주거/개발 5축 점수, 총점·등급, 강점/리스크/다음 액션 요약. sitedia는 그림만 주고 해석은 사용자 몫.
2. **부동산 가치 데이터**: 국토부 실거래가(RTMS), 아파트·오피스텔 단지, 건축물대장 — sitedia에는 가격·단지 정보가 전혀 없음(공시지가만 필지 선택 시 표시).
3. **미래 계획 정보**: 계획 철도 노선, 계획 주택(공급 예정), 재개발·재건축 정비사업 구역 경계. sitedia는 현황 위주(지구단위계획 정도).
4. **생활 인프라 POI**: 학교(교육), 공원·산, 역까지 거리 — 입지 가치 관점의 POI 분석. sitedia 교통 패널은 역·정류장 점만.
5. **편집 가능한 PPT 보고서(약 24장)**: 표지~결론까지 서사가 있는 보고서를 바로 발표에 사용. sitedia는 낱장 이미지 + 조판 시트(로그인)까지.
6. **프로젝트 저장/계정(마이페이지)**: 분석 결과를 다시 열 수 있음. sitedia는 결과 보관 안 함.
7. **노선도 표현(철도 노선·범례)**: 호선 색·노선 레전드가 있는 지하철 오버레이.
