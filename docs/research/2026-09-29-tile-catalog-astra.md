## 2. 분석 타일 목록

### 2.1 공통 집계·판단 원칙

**[추정] 분석 영역과 집계 단위**

- `C`: 주소 중심점과 선택 반경으로 만든 원형 분석 영역.
- `A(X)`: 미터 기반 투영좌표계에서 계산한 도형 `X`의 면적.
- 점 시설은 `C` 안에 있는 고유 시설을 집계한다.
- 건물·필지·사업구역은 `C`와 교차하는 객체를 찾고, 면적은 `C` 내부로 잘라 계산한다.
- 건물 수·단지 수·필지 수·사업 수는 서로 다른 지표다.
- 세대수·거래건수처럼 면적에 비례한다고 볼 수 없는 값은 경계 교차 면적으로 나누지 않는다.
- 최근접 검색은 조회 범위를 표시한다. 결과가 없으면 “전국에 없음” 대신 “반경 내 확인되지 않음”으로 쓴다.
- 지도 표시 토글은 기본 집계를 바꾸지 않는다. 분석 필터를 바꾸었을 때만 새 결과를 만든다.

**[추정] 좋음·보통·주의의 적용 범위**

접근거리처럼 방향이 명확한 항목에만 제한적으로 적용한다. 아래 거리 기준은 **내부 선별용 제안이며 공식 역세권·통학권·보행권 기준이 아니다.** 화면과 PPT에도 기준을 함께 표시한다.

| 구분 | 판단 방법 |
|---|---|
| 접근성 | 고정된 내부 거리 구간으로 분류하되, 직선거리라는 조건을 붙임 |
| 공급·가격·인구·개발 | 증가·감소·집중·분산·계획단계를 설명. 좋음·나쁨으로 강제 변환하지 않음 |
| 규제·배정 | 확인된 지정·연결 관계를 설명. 건축 가능성·배정 확정을 확대 해석하지 않음 |
| 데이터 품질 | `확인 / 일부 미확인 / 미확인`으로 별도 표시. 입지 평가와 혼합하지 않음 |

판단 문장은 **사실 → 의미 → 필요한 확인** 순서로 작성한다. 핵심 입력이 없으면 좋음·보통·주의를 내리지 않고 판단을 유보한다.

### A01. 입지·대중교통

**답하는 질문:** 운영 중인 철도와 버스에 얼마나 가까운가?

| 핵심 지표 | 정의·단위·계산식 |
|---|---|
| 최근접 운영역 거리 | `min(중심점→운영역 출입구 거리)`, m. 출입구가 없으면 역 대표점 거리로 별도 표시 |
| 반경 내 운영역 수 | 출입구·노선별 중복을 제거한 고유 역 수, 개 |
| 이용 가능한 철도 노선 수 | 반경 내 운영역에 연결된 운영 노선의 고유 개수, 개 |
| 최근접 버스정류장 거리 | `min(중심점→운영 정류장 거리)`, m |
| 버스 정류장·경유 노선 수 | 정류장 ID 기준 개수와 노선 ID 기준 고유 개수. 방향별 정류장은 별개, 같은 노선은 중복 제거 |

**한 줄 판단 규칙 [추정]**

- 철도 거리: `500m 이하=좋음`, `500m 초과~1,000m 이하=보통`, `1,000m 초과=주의`.
- 버스 거리: `300m 이하=좋음`, `300m 초과~600m 이하=보통`, `600m 초과=주의`.
- 두 등급을 합산하지 않는다. 예: **“철도 접근은 가까운 편이고 버스도 인접하나, 실제 보행 경로는 미확인이다.”**
- 운영 빈도·배차를 확보하지 않았다면 정류장 수를 서비스 수준으로 해석하지 않는다.

**필요 데이터:** 운영 철도·출입구·노선 연결, 전국 버스정류장, 확보 가능한 정류장–노선 연결. `reference`와 `osm`의 로컬 자료.

**미확인 처리:** 운영 여부·출입구·노선 연결을 필드별로 구별한다. 조회 반경이 판정 구간보다 작으면 ‘주의’ 대신 “현재 반경 밖은 미조회”. 직선거리를 도보시간으로 환산하지 않는다.

### A02. 학교·통학구역

**답하는 질문:** 주변에 어떤 학교가 있고, 대상 주소의 통학구역은 무엇인가?

| 핵심 지표 | 정의·단위·계산식 |
|---|---|
| 학교급별 운영 학교 수 | 초·중·고별 고유 학교 ID 수, 개교 |
| 최근접 초등학교 거리 | 중심점에서 운영 초등학교 정문까지 직선거리, m. 정문 미확보 시 학교 대표점 |
| 연결 초등학교 수·명칭 | 대상 주소가 속한 유효 통학구역과 공식 연결된 학교 집합, 개교·명칭 |
| 연결 학교별 거리 | 각 연결 학교까지 직선거리, m. 공동통학구역이면 모두 표시 |

**한 줄 판단 규칙 [추정]**

- 공식 연결 학교가 확인된 경우에만 통학거리 관점으로 `500m 이하=좋음`, `500~1,000m=보통`, `1,000m 초과=주의`를 제안한다.
- 공동통학구역은 학교별 거리를 표시하며 가장 가까운 학교를 배정학교로 확정하지 않는다.
- 학구 미확보 시: **“최근접 초등학교는 확인되나, 해당 주소의 통학구역은 미확인이다.”**
- 학교 수·거리로 교육 품질이나 학군 우열을 평가하지 않는다.

**필요 데이터:** 학교 위치·학교급·운영 상태, 학구 도형, 학교 연결표, 적용 학년도·고시. `reference`.

**미확인 처리:** 도형과 연결표 중 하나라도 없으면 통학구역 판단을 유보한다. 원의 중심점이 확인되었다고 반경 전체가 같은 학구라고 표시하지 않는다.

### A03. 생활편의·상가

**답하는 질문:** 일상적으로 필요한 시설이 반경 안에 어떻게 분포하는가?

| 핵심 지표 | 정의·단위·계산식 |
|---|---|
| 업종군별 시설 수 | 식료품·의료/약국·음식/카페·생활서비스 등 고정 분류별 고유 시설 수, 개 |
| 기초 생활시설 확인군 | 식료품점·의원·약국·생활서비스 중 반경 내 확인된 군 수, `0~4군` |
| 업종군별 최근접 거리 | 각 군의 `min(중심점→시설 거리)`, m |
| 상가 밀도 | `확인된 상가 수 ÷ A(C)`, 개/㎢ |

**한 줄 판단 규칙 [추정]**

**“기초 생활시설 4군 중 n군이 확인되며, 반경 내 미확인 항목은 ○○이다.”**

좋음·보통을 강제하지 않는다. 시설이 존재하는 것과 규모·운영시간·품질이 충분한 것은 다르다. 누락된 군은 확인 과제로 제시한다.

**필요 데이터:** 소상공인 상가정보, 업종 코드 매핑, 의료기관·약국 보완 자료, 영업 상태. `reference`.

**미확인 처리:** 원천 미등재와 실제 시설 부재를 구별한다. 동일 시설의 복수 원천 중복을 제거하며, 건물 하나에 여러 점포가 있는 것은 보존한다. 폐업 여부 미확인 시 “자료 기준일 당시 등재”.

### A04. 공원·녹지

**답하는 질문:** 이용 가능한 공원과 물리적 녹지가 얼마나 가까이, 얼마나 있는가?

| 핵심 지표 | 정의·단위·계산식 |
|---|---|
| 최근접 공원 입구 거리 | 운영 공원의 확인된 입구까지 최소 직선거리, m |
| 운영 공원 수 | 반경에 교차하는 운영 공원의 고유 개수, 개 |
| 반경 내 공원 면적 | `A(C ∩ union(운영 공원 경계))`, ㎡ |
| 녹지·수변 면적률 | 녹지와 수면을 분리해 각각 `교차 합집합 면적 ÷ A(C) ×100`, % |

**한 줄 판단 규칙 [추정]**

입구가 확인된 공원은 `500m 이하=좋음`, `500~1,000m=보통`, `1,000m 초과=주의`의 접근거리 기준을 적용한다.

입구가 없으면 **“공원 경계는 인접하지만 실제 진입 위치는 미확인이다.”**로 제한한다. 지정 공원과 실제 조성·개방 공원을 구별한다.

**필요 데이터:** 공원 표준정보, 운영 상태, 공원·녹지·하천 도형, 출입구. `reference`, `core`, `osm`.

**미확인 처리:** 경계가 없으면 공원 전체 면적을 반경 내부 면적으로 넣지 않는다. 면적으로 가상의 원을 만든 거리를 실제 접근거리처럼 표시하지 않는다.

### A05. 기존 주거 공급

**답하는 질문:** 현재 어떤 주거 재고가 형성되어 있는가?

| 핵심 지표 | 정의·단위·계산식 |
|---|---|
| 주거 유형별 단지·건물 수 | 아파트 단지, 오피스텔 건물, 기타 주거 건물을 구분한 고유 개수 |
| 확인 세대·호수 | 입주·사용승인된 대상의 세대수 합계. 오피스텔 호수는 별도 합계 |
| 준공연도 중앙값 | 사용승인연도를 확인한 건물의 중앙값, 년 |
| 오래된 건물 비중 | 분석 기준일 대비 경과연수 `30년 이상` 건물 수 ÷ 준공일 확인 건물 수, %. **[추정: 현황 구간]** |
| 세대당 주차대수 | 주차와 세대수가 모두 있는 같은 단지 집합의 `Σ주차대수 ÷ Σ세대수`, 대/세대 |

**한 줄 판단 규칙 [추정]**

**“주거 재고는 ○○ 유형 중심이며, 준공일이 확인된 건물 중 오래된 건물 비중은 x%이다.”**

재고가 많으면 좋음, 오래되면 재건축 가능으로 판정하지 않는다. 주차비율도 법정 기준·실사용 여건 없이 부족 판정을 하지 않는다.

**필요 데이터:** GIS건물, 대장 총괄·표제부, 단지–동 연결, K-APT 보완. `core`, `reference`.

**미확인 처리:** 세대수 미상은 합계에서 제외하고 미상 단지 수를 병기한다. 준공일 확인률을 함께 표시한다. 단지 집계는 대표점 포함 방식으로 고정하고 경계에 걸친 단지는 별도 표시한다.

### A06. 분양·입주예정 공급

**답하는 질문:** 어느 시기에 어떤 공급이 예정되어 있는가?

| 핵심 지표 | 정의·단위·계산식 |
|---|---|
| 진행 단계별 사업 수 | 분양공고·착공·입주예정 등 최신 확인 단계별 사업 수, 건 |
| 향후 입주예정 물량 | 기준일 이후 `12개월`, `13~24개월`의 예정 세대 합계. **[추정: 표시 기간]** |
| 일정 미확인 물량 | 예정 세대수는 있지만 입주 시점을 확정하지 못한 합계, 세대 |
| 기존 재고 대비 예정 비율 | 같은 주택 유형·집계 범위의 `향후 24개월 예정 세대 ÷ 확인 기존 세대 ×100`, % |

**한 줄 판단 규칙 [추정]**

**“확인된 입주예정 물량은 ○○ 기간에 집중되며, 일정 미확인 물량이 별도로 존재한다.”**

공급 과잉·부족은 흡수 수요·미분양 등 없이 판정하지 않는다. 비율의 분모가 부분 재고이면 참고치로만 제공한다.

**필요 데이터:** 청약홈 공고, 입주예정 파일, 주택 인허가·착공 자료, 사업–단지 연결. `market`, `core`.

**미확인 처리:** 변경·재공고는 최신 사업 상태로 정리한다. 청약홈·입주예정·정비사업에 중복 등장한 물량은 한 번만 집계한다. 월 단위 일정에 임의의 일을 붙이지 않는다.

### A07. 매매 실거래

**답하는 질문:** 어떤 주택이 얼마에 거래되었으며, 관측된 거래가격 분포는 어떠한가?

| 핵심 지표 | 정의·단위·계산식 |
|---|---|
| 유효 거래건수 | 선택 기간·유형·면적대의 해제되지 않은 거래 수, 건 |
| ㎡당 가격 중앙값 | 거래별 `거래금액 ÷ 전용면적`의 중앙값, 만원/㎡ |

가격 상승을 좋음으로 평가하지 않는다. 비교 기간별 유효 거래가 **10건 미만이면 변화 판단을 유보**하는 내부 최소 기준을 제안한다. 이 기준은 통계적 신뢰도 보장이 아니다.

**필요 데이터:** 유형별 RTMS, 해제·정정 상태, 계약일, 면적, 건물·단지 위치 연결. `market`.

### A09. 정비사업

|---|---|

사업이 많으면 호재라고 판단하지 않는다. 출처에 지정된 재검토일을 넘긴 사업에는 자료 확인 주의를 표시한다.

**필요 데이터:** 전국·지역별 사업 속성, 정비구역 경계, 고시·단계 이력. `market`.

**미확인 처리:** 행정구역 카탈로그만 있는 사업은 반경 집계에서 제외한다. 신축 거래 발생만으로 사업 준공을 확정하지 않는다. 서로 다른 사업 유형의 단계를 억지로 동일한 진행률로 환산하지 않는다.

### 3.2 점수 엔진 처리 결론

**[추정] 새 앱에서 `computeAnalysisScores`와 점수 기반 서술 생성은 사용하지 않는다.**

근거는 다음과 같다.

- 공급 증가가 수요자·사업자 모두에게 좋은 방향은 아니다.
- 정비사업 수는 기회뿐 아니라 공사·이주·일정 불확실성을 뜻할 수 있다.
- 경계 확인률은 데이터 품질이며 입지 경쟁력이 아니다.
- 반경·자료 누락·표시 필터에 따라 점수가 달라질 수 있다.
- 현재 가중치와 등급 경계에는 코드 밖의 검증 근거가 제시되어 있지 않다.

재사용 대상은 거리·고유 개수·면적 계산, 공통 포맷, 원천 실패 처리, 미확인 표시다. 기존 앱과 병행하는 동안 기존 엔진은 남길 수 있지만 새 타일 계약에 점수를 이식하지 않는다.

### 4.1 채움률·구성비 공통 규칙

**[추정] 채움률을 다음처럼 분리한다.**

| 기호 | 의미 |
|---|---|
| `F속성` | 해당 속성이 유효한 객체 수 ÷ 확보한 대상 객체 수 |
| `F면적` | 유효하게 자료·계산 결과를 확보한 면적 ÷ 분석 대상 면적 |
| `F시간` | 유효한 관측 시간 수 ÷ 예정 관측 시간 수 |
| `F연결` | 공간·객체 연결에 성공한 원천 레코드 수 ÷ 연결 대상 레코드 수 |

모두 백분율로 표시하되 **분자·분모·기준일을 함께 제공**한다.

- 채움률은 확보한 자료 안에서의 완전성이다. 실제 세상의 모든 객체를 확보했다는 뜻이 아니다.
- 수집 대상 지역의 확보 여부는 별도의 `지역 커버리지`로 표시한다.
- 분모가 없거나 원천의 조사 범위를 모르면 `산정 불가`다. 정상 조회 결과가 없으면 `대상 없음`.
- 속성 미상, 적용 대상 아님, 자료 미확보를 서로 다른 범주로 보존한다.
- 서로 겹치는 구역은 단순 면적 합계를 사용하지 않는다.
- 연속값 구간은 원칙적으로 **하한 포함·상한 제외**, 마지막 구간은 상한 개방으로 통일한다.
- 범례를 숨겨도 구성비 분모는 유지한다. 분석 필터 변경과 표현 숨김을 분리한다.

### 6.2 모든 타일의 PPT 계약

**[추정] `tile_result`에 다음 의미를 보장한다.** ②의 구조를 재설계하지 않고 세부 결과에 반영한다.

| 구분 | 필요한 내용 |
|---|---|
| 조건 | 주소·중심·반경, 필터, 기간, 시뮬레이션 조건 |
| 지표 | 값·단위·계산식 버전·분자·분모·미확인 상태 |
| 판단 | 규칙 ID·적용 조건·근거 지표·판단 문장 |
| 표현 | 범례 구간·카메라·표시 레이어·앞/뒷면 |
| 출처 | 실제 사용 원천·자료 기준일·수집일·버전 |
| 제한 | 미상·추정·비공개·부분 확보·계산 미완료 |

**슬라이드 변환 규칙**

- 분석: 지도 + 핵심 지표 + 한 줄 판단.
- 도판: 도판 + 범례 + 채움률. 뒷면은 구성비 + 분모 + 미상.
- 시뮬레이션: 고정 컷 + 결과 수치 + 계산 조건.
- 스택: 겹친 그림 + 층 이름 + 상속한 출처·한계.
- 조판: 각 하위 타일의 식별·조건을 유지하고 공통 출처를 정리.
- 모든 장: 출처·자료 기준일·미확인 표시. 작성일을 자료 기준일로 대체하지 않음.

기본은 **타일 앞면당 한 장**이다. `앞면/뒷면/둘 다` 출력 선택은 명시적으로 저장한다. 화면에서 잠시 뒤집어 놓았다는 이유로 다음 PPT의 출력 면이 바뀌지 않게 한다.

긴 상세 목록은 자동으로 여러 장 붙이지 않는다. 사용자가 펼친 목록에서 **‘상세 페이지 추가’**를 선택하면 별도 출력 항목을 만든다. 기본 장에는 표시 건수와 전체 건수를 밝힌다.

## 7. 우선순위

### 7.1 v1의 정의

**[추정] v1은 전국의 임의 주소에서 로컬 자료로 반경을 분석하고, 사용자가 필요한 타일을 골라 신뢰할 수 있는 PPT와 기본 공간 파일을 만들 수 있는 첫 내부 버전이다.**

### 7.5 첫 내부 버전의 완료 기준

**[추정] 구현 검증 시 다음을 확인한다.**

- 행정구역 경계에 걸친 반경에서도 관련 지역 자료가 모두 조회된다.
- 같은 입력·manifest·계산 버전의 화면·구성비·PPT 수치가 일치한다.
- 객체 중복, 교차면적, 세대수·사업 물량의 집계 기준이 설명 가능하다.
- 자료 실패·비공개·미확인·실제 0건이 구별된다.
- 층수와 미터 높이, 직선거리와 보행거리, 계획시설과 운영시설이 혼합되지 않는다.
- 모든 출력 장에 사용한 출처·자료 기준일·미확인 사항이 보인다.
- 타일 추가·제거·순서·뒤집기·저장 후 다시 열기가 출력 설정과 일치한다.
- DXF·GLB를 실제 수신 프로그램에서 열어 단위·위치·축·형상을 확인한다.
- 계산 취소·실패 후 부분 결과를 정상 완료 결과로 내보내지 않는다.

이번 작업에서는 위 검증을 실행하지 않았다. 코드와 문서 검토를 바탕으로 완료 조건을 설계했다.

## 8. 미결 질문

아래 질문은 설계를 진행하기 위한 재승인 요청이 아니라, 병합 후 제품 기준을 다듬는 데 필요한 사용자 판단이다.

1. **내부 앱에서 만든 PPT·DXF·3D 파일을 외부 발주처·협력사에도 전달하는가?** 전달한다면 A0의 이용권리 검토 범위에 해당 출력과 전달을 포함해야 한다.
2. **회사에서 이미 사용하는 접근거리·공급·가격 판단 기준이 있는가?** 없다면 본문의 거리 기준만 내부 제안으로 표시하고, 공급·시세 등은 중립적인 사실 판단을 유지한다.
3. **첫 내부 검수에 사용할 실제 주소와 기대 보고서가 있는가?** 있으면 해당 결과를 기준으로 초기 보드의 기본 노출 순서를 정하되, 용도 프리셋은 만들지 않는다.
