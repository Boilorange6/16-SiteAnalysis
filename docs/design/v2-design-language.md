# v2 디자인 언어 — 결정 기록

v2 화면·타일·펼침 창·PPT가 같은 모양과 같은 말로 보이게 하는 규칙이다. **사용자가 확정한 결정만** 적는다. 새 화면을 만들거나 고치는 작업(사람·실행자 모두)은 먼저 이 문서를 읽고 따른다. 여기에 없는 새 패턴이 필요하면 시안을 만들어 사용자 승인을 받은 뒤 이 문서에 추가한다.

- 적용 범위: `src/components/v2/*`, `src/lib/v2/ui/*`, `src/lib/v2/report/*`(PPT), 가이드 페이지.
- 구현 기준 코드: 숫자 서식 `src/lib/v2/ui/tile-view.ts` `formatMetricValue`·`formatDistanceM`, 레이어 색·라벨 `src/lib/v2/ui/map-layers.ts`, 대지 표식 `src/components/v2/map-figure.tsx`.
- 색 토큰 정리(하드코딩 hex → 토큰)는 W5 작업. 그 전까지 새 코드도 아래 값을 그대로 쓴다.

## 1. 기본 원칙
| 원칙 | 규칙 |
|---|---|
| 색에만 기대지 않기 | 상태·강조·대지 표시는 모양/외곽선/글자로도 구분된다(흑백 인쇄·색각 안전). |
| 화면 = 보고서 | 카드·펼침 창·PPT는 같은 컴포넌트(`MapFigure`)로 그린다. 화면에서 고정한 것은 PPT에 그대로 나온다. |
| 지도를 가리지 않기 | 지도 위 오버레이는 방위표·축척·대지 표식·고정 라벨만. 범례는 지도 아래 한 줄 가로 띠로 분리하고 제목·출처·패널은 지도 밖에 둔다. |
| 사용자 말로 쓰기 | 개발 용어·내부 id·원천 파일명(TL_SPBD_BULD 등)·영어 계절명 노출 금지. |
| 호버 전용 금지 | 마우스 호버로만 되는 기능은 없다. 같은 것을 클릭/탭/키보드로 할 수 있어야 한다. |

## 2. 글꼴
- 제목(타일 제목·화면 제목): Do Hyeon(`--font-dohyeon`), 대체 Noto Sans KR.
- 본문·숫자·라벨: Noto Sans KR(`--font-noto-kr`). 숫자가 세로로 줄 서는 곳은 `tabular-nums`.

## 4. 숫자·단위 (`formatMetricValue`)
- `%`, `°C`, `m/s`, `도`: 소수 1자리. 면적·밀도·인원·금액(㎡, ha, 동/㎢, 명/㎢, 원/㎡ …): 정수. 그 밖: 최대 소수 2자리.
- 천 단위 쉼표(연도 제외). 거리: 1 km 미만 `480m`, 이상 `1.2 km`.
- 값이 없으면 `미확인`. 추정값은 `추정` 배지를 붙이고 확정값과 섞어 세지 않는다(예: 건물 높이 확정/추정 분리).

## 5. 타일 카드 구조 (2026-10-06 승인, 지도 면 재구성)
1. **헤더**(지도 밖, 40 px): 점 + 제목 + 핵심 숫자. 그 아래 한 줄에 숫자의 짧은 의미 라벨(예: "1990년대 이전 준공"). 오른쪽 버튼: 보고서 체크, 펼치기 ↗, ⋯ 메뉴, ↺ 요약.
2. **지도**: 남은 높이 전부. 반경 원이 지도 높이를 채우는 축척.
3. **범례**: 지도 바로 아래 §6의 모든 항목 가로 스크롤 띠.
4. **출처**(지도 밖, 24 px, 한 줄 말줄임 — 전체는 상세 창).
- 버튼 시각 크기 32 px, 누르는 영역 44 px 이상, 포커스 링 보임.
- ⋯ 메뉴는 팝오버(role=menu, Esc·바깥 클릭으로 닫힘, 포커스 복귀). 타일별 설정(보고서 그림, 고정 라벨 모두 끄기 등)은 여기로.
- 앞뒷면 전환 버튼은 요약면·지도면 모두 헤더 우상단에 둔다. 공통 `mfBtn`(시각 32 px, 히트영역 44 px)을 쓴다.
- 보드는 상시 편집 상태다. 드래그 핸들은 카드 호버·포커스 때 보이고, coarse 포인터에서는 항상 보인다. 순서·스택·조판·삭제는 ⋯ 메뉴에서도 조작한다.
- 열 선택은 현재 숫자 하나만 보이는 44×44 px 버튼(숫자 아래 2 px 밑줄)으로 제공하고, 누르면 바로 아래 2·3·4·5·6 목록을 연다. 1280 px 이상은 왼쪽 72 px 여백 안의 sticky rail, 그보다 좁으면 같은 버튼을 `더 보기` 안에서 재사용한다. 목록은 현재 값 검정 칸·Esc/바깥 클릭 닫기·↑↓/Enter/Space·포커스 복귀를 보장한다.
- 타일 추가는 rail과 `더 보기`에서 제거하고, `#v2-board-grid` 마지막에 1칸 점선 `+ 타일 추가`를 둔다. 열·스택·조판 흐름의 마지막에 따라가며 roving/드래그 항목에는 포함하지 않는다. 열면 같은 자리가 2행 임시 타일이 되어 라벨 있는 검색·44 px 닫기·분류/색/제목 목록을 보여 준다. 검색은 한글 부분 일치, 중복 추가는 보드 끝 복제, 추가 직후 링과 기존 되돌리기 토스트를 쓴다.
- 크기 핸들은 카드 좌하단·우하단에 두고, 44 px 히트영역과 16 px 모서리 표식을 쓴다. 호버·포커스 때 보이며 coarse 포인터에서는 항상 보인다. 1열에서는 숨긴다.

## 5-2. 보드 보조 조작 (2026-10-16, 열 선택·마지막 추가 칸)
- 보드 보조 조작은 `--ink`/`--muted`/`--line`/`--black` 토큰을 사용하고, 일반 텍스트 대비 4.5:1 이상·컨트롤 최소 44×44 px·2 px 포커스 링을 유지한다. 아이콘 대신 숫자·`+`·`×`의 텍스트 모양을 사용하며 이모지는 쓰지 않는다.
- 펼침·임시 타일은 150–200 ms `cubic-bezier(0.23, 1, 0.32, 1)`로 `transform`과 `opacity`만 바꾼다. 시작은 `scale(0.96)`이며 트리거 쪽 transform-origin을 쓴다. 키보드로 연 목록은 움직임을 생략하고, `prefers-reduced-motion`에서는 transform을 제거하고 opacity만 남긴다. hover는 `(hover: hover) and (pointer: fine)` 안에서만 선언한다.

## 6. 범례
- 카드와 펼침 창 모두 범례는 **지도 아래의 한 줄 가로 스크롤 띠**다. 지도 안에 겹쳐 놓지 않는다.
- 항목을 줄이거나 `+n`으로 숨기지 않고 모든 항목을 렌더링한다. 항목이 넘치면 **범례 띠만** `overflow-x: auto`로 스크롤하며 줄바꿈하지 않는다. 페이지와 카드는 가로 스크롤하지 않는다. 팝오버·더보기 창은 만들지 않는다.
- 정렬은 **강조 대상(최근접·대지 관련) 먼저**, 그다음 표시 개수 내림차순, 동률은 엔진이 낸 순서를 유지한다. 띠의 시작점은 지도 콘텐츠의 시작점과 맞추고 항목 간 간격은 8 px 이상으로 둔다.
- 범례 이름은 같은 표시 이름끼리 하나로 묶는다(`legendItems`가 라벨로 중복 제거). 강조 매칭도 레이어 id가 아니라 **범례 표시 이름 기준**이다.
- 각 항목은 견본·표시 이름·필요한 값/구간 경계를 함께 가진다. 상대 구간·히트맵·단계구분도는 실제 최소·최대 또는 경계값을 생략하지 않는다.
- 모든 항목은 접근 가능한 native button으로 제공하고 `aria-pressed`/선택 상태를 노출한다. 마우스 `hover`, 키보드 `focus`, 터치 `tap`에서 같은 강조를 제공한다. 항목을 클릭하거나 Enter/Space로 누르면 강조가 고정되고 다시 누르거나 Esc로 해제한다. 고정 상태는 띠를 벗어나도 유지한다.
- 시각 항목은 최소 24 px로 읽히게 하고 실제 터치/포인터 누름 영역은 44×44 px 이상으로 확보한다. 포커스 링은 항상 보이며 2 px 이상, 상태 대비 3:1 이상으로 한다. 포커스가 가로로 숨은 항목에 가면 해당 항목을 띠 안으로 스크롤한다.
- 연속 범례(래스터)는 같은 띠 안의 얇은 막대와 최소·최대/경계값 텍스트로 표시한다.

## 8. 지도 요소 라벨 (⑦, 2026-10-07 승인; W2b 계약 반영 2026-10-09)
- **필드 계약**: 모든 feature·polygon·line은 필요할 때 `name`, `sublabel`, `labelPriority`를 함께 낸다. `name`은 원천 지물명(출구처럼 원천 식별자를 붙여야 하는 경우에만 타일이 만든 표시명), `sublabel`은 타일이 단위·쉼표까지 끝낸 값 문자열, `labelPriority`는 자동 라벨 등급 `0/1/2`다. 값이 없으면 `null`이며 `미상`이나 레이어명을 값처럼 덧붙이지 않는다.
- **자동 라벨**: `labelPriority ≥ 1`이고 `name`이 있는 요소만 후보로 삼아 `name`과 보조 문구를 말풍선으로 표시한다. 같은 문구는 한 번만 내고, 같은 등급에서는 엔진 출력 순서를 유지한다. 지도 높이로 계산한 좌우 칸이 허용하는 우선순위 상위 후보만 남기며 나머지는 숨긴다. 자동 라벨에서 범례명·내부 id를 뒤에 붙이지 않는다. D03·D04·D05·D12는 처음에 자동 후보를 만들지 않고, 사용자가 고정한 요소만 표시한다.
- **호버·고정 라벨**: A05/A06과 같은 흰 바탕·검은 테두리·검은 점·꺾인 지시선 말풍선이다. `name`이 있으면 첫 줄을 굵게 쓰고, `sublabel`의 줄바꿈 또는 ` · ` 구분을 다음 줄에 최대 3줄까지 표시한다. 이름이 없으면 범례 표시 이름을 첫 줄로 쓴다. 비어 있는 `sublabel`과 `미상`은 생략한다. 예: `고덕 센트럴 푸르지오 102동 · 36층`, `고덕그라시움 · 3,028만원/㎡ · 109건`.
- **최근접 계약**: 최근접으로 표시하는 지물은 화면에서 임의로 고른 점이 아니라 **그 지표의 값을 정한 바로 그 지물**이어야 한다. 엔진이 거리·시간·접근성 등의 metric을 계산한 동일 feature에 `highlight: true`, 이름, 서식한 거리/값, 필요하면 대지 연결 점선을 붙인다. `*_nearest`라는 레이어 이름만으로 다른 지물을 강조하지 않는다.
- 거리 표기는 `직선 412m` / `직선 1.2 km`처럼 `formatDistanceM` 규칙을 따른다. A01·A02·A03·A10·D13의 버스·역·학교·상가·도로는 문자열을 직접 조립하지 않는다.

## 9-3. PPT 내보내기 미리보기 창 (2026-10-15 직접 조작 결정)
- **2026-10-20부터 §11 보고서 모드로 대체되었다.** 타일 모드의 PPT 버튼과 이 창은 없어졌고, 페이지 위 직접 조작(라벨 고정·범례 강조·탭 8핸들 변형)은 보고서 모드의 편집 페이지가 이어받는다. 아래는 이력으로 남긴다.
- PPT 버튼은 즉시 다운로드하지 않고 `role=dialog` 미리보기 창을 연다. 페이지가 주인공이 되도록 데스크톱은 접을 수 있는 왼쪽 필름스트립·가운데 최대 16:9 페이지·페이지 위 떠 있는 작은 툴바만 두며, 좁은 화면은 페이지·툴바·하단 필름스트립 순서다. 우측 설정 패널과 별도 라벨·범례 설정 섹션은 두지 않는다.
- 큰 페이지의 지도 요소를 누르면 기존 `MapFigure.onFeaturePin` 경로로 해당 페이지 `pinnedKeys`를 토글한다. 페이지 style에 `pinnedKeys`가 처음 생길 때는 현재 보드 라벨을 기준으로 시작하며, 고정 말풍선을 다시 누르면 제거한다. 페이지 위 안내는 `지도 요소를 누르면 라벨, 범례를 누르면 강조`를 사용한다.
- 큰 페이지의 범례 판은 PPT 배치와 같은 `slideLegend` 항목을 native `button`으로 그린다. 항목을 누르거나 Enter/Space로 누르면 `legendFocus`를 저장하고 같은 항목을 다시 누르면 `null`로 돌아간다. 선택 항목은 굵은 글자·체크·테두리로 표시하고, 나머지는 PPT와 같은 약화 규칙을 따른다. 호버·포커스는 지도 강조를 미리 보고, 터치 탭은 고정 토글을 수행한다.
- 지도 확대/축소·대지 중앙 정렬·요약 탭 on/off·탭 배치 초기화·`라벨 초기화(보드 라벨 따르기)`는 페이지 위 툴바에서 조작한다. 선택된 요약 탭의 프레임 바깥에 44 px 숨김 칩을 두고, 툴바에서 다시 켠다. 제목·요약·범례 탭의 44 px 핸들을 직접 드래그해 축별·양축 크기와 위치를 미리 보고, 탭 포커스 후 화살표/Shift+화살표로도 조절한다.
- 제목·요약·범례 탭은 클릭/Enter로 선택하고, 선택 프레임 안쪽 드래그는 이동, 네 변 중앙 핸들은 한 축만, 네 모서리 핸들은 양축 크기 조절이다. 저장 좌표는 `panels`의 슬라이드 비율 0..1 사각형이며, 존재할 때 미리보기와 PPT가 같은 사각형을 쓴다. 기존 `*Scale`은 레거시 배치와 폰트 기준으로만 남고 직접 변형 시 `panels`가 우선한다. 화살표는 1% 이동, Shift+화살표는 1% 크기 조정이며 가장자리·안전 여백·다른 탭 가장자리에 1% 스냅 가이드를 보인다. 선택되지 않은 탭의 첫 클릭은 선택, 범례 항목(`data-panel-action=legend-item`)은 항상 강조 토글로 판정한다. 선택된 요약만 프레임 바깥 원형 칩으로 숨길 수 있고, 제목·범례는 숨김 칩을 두지 않는다.
- 썸네일 단일 선택·Ctrl/⌘ 토글·Shift 범위 선택, 접힌 필름스트립, 필름스트립 끝의 `+ 페이지`(현재 페이지 뒤에 추가)와 썸네일 `⋯` 메뉴, 추가 장 삭제, PPT 내보내기, Esc 닫기·포커스 트랩·닫은 뒤 opener 복귀를 유지한다. 다중 선택의 툴바 지도/요약/탭 배치 초기화 조작은 선택 장 전체에 적용하고 `N장에 적용`으로 알린다. 지도 라벨·범례 직접 조작은 큰 페이지 한 장에만 적용하며 그 사실을 짧게 표시한다.
- 모든 조작은 44 px 히트영역·보이는 포커스 링·150–200 ms 상태 전환·짧은 동작 툴팁을 갖는다. 작은 지도 점은 투명 히트 원으로 확장하고, `prefers-reduced-motion`에서는 전환을 즉시 처리한다. 작은 화면에서 가로 스크롤은 필름스트립에만 허용한다.

- **페이지 추가(E1):** 머리는 `페이지 추가`, 선택 페이지가 있으면 `N쪽 뒤에`, 없으면 `맨 뒤에` pill과 닫기를 보여 준다. 추가 카드는 4:3 채움 미리보기 2열 격자이며 아래 흰 띠에 11 px 이름을 겹쳐 놓고, 빈 페이지는 점선 미리보기다. 아래에는 구분선과 아이콘+글자 보조 버튼 `추천 구성으로 다시 시작`·조건부 `이전 보고서 불러오기`를 둔다.
- **분석 타일(D1):** 검색·분류 칩과 기존 클릭 추가·단일 끌기·비교 선택/생성·Enter/Space 의미를 보존한다. 선택 칩은 `#15171c` 바탕·흰 글자이고, 타일 카드는 4:3 2열이다. 각 카드에는 실제 계획 슬라이드를 `SlideSurface mode="thumb"`로 그리며 `IntersectionObserver`로 보이는 카드만 마운트하고, `N쪽` 사용 배지·비교 체크를 겹쳐 둔다.
- **요소와 팝오버(E2·E3·E4·E5):** 글자 크기 창은 범위 2칸·요소 5줄과 `기본 크기로` 보조 버튼을 둔다. 레이아웃 창은 4:3 도식 썸네일 2×2 격자, 메모 창은 240 px 공통 머리·150 px textarea·`저장됨`을 쓴다. 글상자 창은 제목·본문 글·주석·출처 중 종류를 고르는 공통 팝오버이며 각 선택 뒤 놓기 모드로 전환한다.
- **글상자 T2:** 종류를 고르면 슬라이드 위 커서가 crosshair가 되고 기본 크기 점선 미리보기가 포인터를 따른다. 클릭 시 슬라이드 안으로 clamp하여 추가하고 즉시 글 고치기 상태로 들어가며, Esc·같은 레일 버튼 재클릭은 취소한다. 놓인 상자는 1.5 px 파란 선택 테두리·8방향 손잡이·이동/Aa/삭제 막대를 쓰고, Delete/Backspace로 삭제한다. 고치기 상태는 2 px 테두리+4 px 링, `− pt +`·굵게·기울임·8색·왼쪽/가운데·삭제·파란 `완료` 막대이며 `TextBox`의 `kind`, `bold?`, `italic?`, 허용된 `color?`, `align?`을 미리보기·복원·PPT에 동일하게 반영한다.
- **요소별 글자 크기(F1·H1):** 값은 배율이 아닌 문서에 저장하는 정수 `pt`다. 제목·요약·범례·지도 라벨·출처(출처 줄·주석)의 5개 값을 두며 우선순위는 `이 페이지 값 > 모든 페이지 값 > 기본값`이다. 기본값·범위는 제목 `18 (12–32)`, 요약 `13 (10–24)`, 범례 `10 (8–16)`, 지도 라벨 `10 (8–18)`, 출처 `9 (7–14)`pt다. F1 `글자 크기` 팝오버는 약 320 px 흰 카드 안에 `모든 페이지 | N쪽만` 2칸 버튼과 요소별 `− 값pt +`를 둔다. 현재 페이지 값을 쓰면 해당 값은 파란 굵은 글자로 보이고, 바뀐 값 수와 `모든 페이지 값으로`를 표시한다. 요소 이름 버튼을 누르면 슬라이드의 해당 요소에 파란 2 px 점선을 보인다.
- **H1 요소 메뉴:** 제목·요약·범례 패널, 지도 라벨, 출처 줄은 우클릭하면 커서 근처의 약 236 px 흰 `role="menu"` 카드에서 같은 pt 조절과 `모든 페이지 | N쪽만` 2칸 선택을 제공한다. 페이지 값이 있을 때만 요소별 되돌리기를, 패널 rect가 바뀌었을 때만 위치·크기 초기화를 보인다. 왼쪽 클릭은 기존 선택·이동·8핸들 크기 조절을 유지한다. 우클릭은 브라우저 메뉴를 막고, Esc·바깥 클릭 뒤 opener로 포커스를 돌린다. Shift+F10·ContextMenu 키와 태블릿의 500 ms 이동 없는 길게 누르기도 같은 메뉴를 연다. 두 UI는 같은 문서/페이지 상태를 읽으며 `+`·`−` 한 번을 기존 history의 한 단계로 기록한다.
- **서랍 초기 상태:** 페이지가 있으면 서랍은 닫힌 채 시작한다. 0쪽일 때만 페이지 서랍을 연다. 지도를 선택하거나 선택 해제해도 서랍을 열거나 닫지 않는다. 390 px에서는 서랍과 설정 카드를 아래 시트로 열고 포커스를 가두며, 도구 막대는 위쪽 가로줄·페이지 줄은 가로 스크롤로 바꾼다.
- **지도 막대:** 지도 막대는 슬라이드 위에 띄우지 않는다. 지도 선택 시 축척 −·현재 축척·축척 +·대지 맞춤·위치 고정·설정만 보이며, 편집 상태에는 축척 −·현재 축척·축척 +·`완료 Esc`만 둔다. `이동` 버튼은 없다. 처음 지도를 선택했을 때 한 번만 `두 번 눌러 지도 편집` 안내 칩을 보이고, 편집 시작 또는 ×로 닫으면 `v2.report.mapEditHint`를 저장해 다시 보이지 않게 한다.
- **지도 조작:** 한 번 누르면 선택, 두 번 누르거나 지도에 포커스가 있을 때 Enter를 누르면 편집을 시작한다. 편집 중 끌기는 이동, 휠은 커서 위치 기준 확대·축소, 두 번 누르기는 누른 위치 기준 한 단계 확대다. 편집 중 방향키는 이동하고 `+`/`=`·`-`는 축척을 조절한다. Esc·지도 바깥 누르기·완료는 편집 종료 → 설정 카드 닫기 → 선택 해제 순서로 한 단계씩 물러난다. 위치를 고정한 상태에서 편집 진입을 시도하면 자물쇠를 600 ms 강조한다. 편집 중 제목·요약·범례 패널은 불투명도 .35와 입력 차단으로 흐려지고, 지도 커서는 `grab`/`grabbing`, 슬라이드 테두리는 파란 3 px와 연한 6 px 테두리다.
- **페이지 줄:** 페이지 줄은 roving tabindex를 쓰며 선택한 썸네일만 Tab 정지점(`tabIndex=0`)이다. ←/→와 Home/End는 페이지를 선택하고, PageUp/PageDown은 입력 중(`input`·`textarea`·`select`·contentEditable)이 아니고 지도 편집 중이 아닐 때만 이전·다음 페이지로 간다. 순서는 끌어 놓기로 바꾸며 놓일 자리에는 3 px 파란 세로 막대, 끄는 썸네일에는 불투명도 .35를 쓴다. 끝 48 px에서는 자동 스크롤한다. 끌기의 대안으로 Ctrl(⌘)+Shift+←/→와 썸네일 메뉴의 앞으로·뒤로를 제공하고, 이동 뒤에는 되돌리기 토스트를 띄운다.
- **설정 카드:** 오른쪽 296 px 카드다. 카드 머리에는 `고정` 토글을 두며, 축척·배경지도·범례 위치 3묶음은 펼쳐 둔다. 레이어·지번 라벨·범례 항목·장식·중심 이동·비교 위치/확대는 native `<details>`로 접고 현재 값을 `<summary>` 한 줄에 요약한다. 390 px에서는 아래 시트다. 설정 카드는 지도를 선택했다고 자동으로 열지 않고 지도 막대의 `설정` 버튼으로만 연다.
- **편집기 글자·간격:** 겉면은 글자 크기 12·13·14·16·20 px와 굵기 400·500·700만 쓴다. 기본 간격은 4·8·12·16·20·24 px이며 버튼 글자는 줄바꿈하지 않고 겉면 전체는 `word-break: keep-all`을 쓴다. 12 px 미만의 본문과 이전의 조작 설명 문장은 노출하지 않고 현재 상태·오류로 대체한다. 카드·막대의 나타남은 180 ms `cubic-bezier(.23,1,.32,1)`과 8 px 이동, 사라짐은 120 ms이며 키보드 조작과 reduced-motion에서는 이동을 생략한다.

- **작업 공간(B·D1·G1):** `min-width:1024px` 이상에서 왼쪽 56 px `toolPill`(44×44 아이콘·툴팁: 페이지·분석 타일·글상자 / 구분선 / 글자 크기·레이아웃·메모) + 가운데 캔버스 + 아래 `pageDock`(썸네일·순서만)으로 구성한다. 서랍은 무대 위에 겹쳐 뜨고, 네 사이드창은 도구 막대에서 열리는 tail 연결 팝오버/서랍이다. 오른쪽 상시 레이아웃 목록과 상시 발표 메모 칸은 두지 않는다. 1023px 이하의 기존 반응형 배치는 유지한다.
- **빈 상태(0쪽):** 점선 판형, `페이지를 추가하세요`, `+ 페이지 추가`·`추천 구성으로 시작`, 옛 저장본이면 `이전 보고서 구성 불러오기`.
- **페이지 줄:** `pageDock`는 `SlideSurface mode="thumb"` 썸네일과 순서 조작만 제공한다. export의 모든 출력 장을 표시하고, 이어지는 장은 `{n}쪽 {제목} n/N`으로 표시한다. 끌기와 ←/→/Home/End로 순서를 바꾸고, 썸네일 `⋯` 메뉴(44 px, Esc로 닫고 포커스 복귀)에 `복제`·`앞으로`·`뒤로`·`삭제`를 둔다. 레이아웃·메모는 이 줄에서 열지 않는다.
- **서랍과 닫기(D1):** 페이지 서랍은 폭 240 px·padding 12 px·공통 머리·40–100% 투명도 range·`N쪽 뒤에`/`맨 뒤에` pill, 4:3 미리보기 2열, 빈 페이지 점선, 보조 버튼 `추천 구성으로 다시 시작`·조건부 legacy 불러오기를 제공한다. 분석 타일 서랍은 검색·칩·4:3 2열 카드·보이는 카드만 `SlideSurface mode="thumb"`로 그리는 실제 렌더·`N쪽` 배지를 제공하며 단일 추가/끌기와 비교 선택을 유지한다. 두 서랍 모두 제목·개수/위치·32 px 투명 X, Esc·바깥 클릭·opener 포커스 복귀를 보장한다.
- **팝오버(G1·E2~E5):** 레이아웃·메모·글자 크기·글상자 창은 도구 버튼의 tail로 연결되고 열린 버튼은 파란색/흰색 active다. 여섯 창은 공통 머리·투명도 조절을 쓰며, 글상자는 종류 선택 뒤 슬라이드 놓기로 이어진다. 글자 크기는 F1의 5개 정수 pt·두 범위 버튼·`기본 크기로`를 쓰고, 레이아웃은 `레이아웃 · N쪽` 4:3 미니어처와 선택 테두리, 메모는 240 px·`발표 메모 · N쪽`·150 px 입력·`저장됨`을 쓴다.
- **글자 크기와 우클릭:** F1과 H1은 `제목·요약·범례·지도 라벨·출처`를 같은 상태로 조절한다. 미리보기는 계획 단계에서 병합된 pt를 읽고 PPT도 같은 병합값으로 계산해 제목·요약·범례·출처의 크기 비율을 일치시킨다. 지도 라벨은 동일한 라벨 배율을 미리보기와 PPT의 `buildMapScene`에 전달한다. 이전 `fontScale`은 읽을 때 문서 5개 값으로 변환하고 새 저장에는 쓰지 않으며, 복원 시 범위 밖 값은 요소별 범위로 자른다.
- **지도 활성화:** 한 번 누르면 선택(파란 테두리)과 지도 설정 카드, 두 번 누르거나 `지도 이동`이면 이동 모드(끌기·휠, 안내 `지도를 끌어 옮기고 휠로 확대합니다 · Esc 또는 바깥을 누르면 끝납니다`). Esc는 이동만 끝내고 선택은 남긴다. `지도 위치 고정`이면 이동·축척 입력을 받지 않고 `잠금 해제 후 이동 가능`을 보인다.
- **떠 있는 지도 툴바:** 지도 선택 시 `−` / `1:{n}` / `+` / `맞춤` / `잠금` / `설정`, 편집 중에는 `−` / `1:{n}` / `+` / `완료 Esc`만 보인다. 제목판·지도·범례를 가리지 않고 무대 폭을 넘지 않는다.
- **축척:** `1:{n}`은 실제로 그린 지도에서 잰다(미터/픽셀 × 프레임 폭 ÷ 종이 폭). 입력은 `1:2,500`·`2500`·`1/2500`, 범위 1:500–1:50,000(밖이면 `1:500부터 1:50,000까지 입력합니다`), 프리셋 1:1,000·2,500·5,000·10,000. 고정한 지도는 판형·레이아웃을 바꿔도 축척과 이동량이 그대로이고 보이는 범위만 바뀐다. PPT 축척 막대도 같은 축척이다.
- **지도 설정 서랍:** 배경지도 4칸 → 범위(축척·프리셋·동/북 이동 m 정수·`대지 맞춤`·`반경 전체`·고정) → 라벨 3종(`대지 주변 지번만`·`보이는 지번 모두`·`끄기`) → 지도 레이어 → 범례(항목별 끌기·체크·↑↓, `보이는 것만`, 위치 3종 `지도 아래`·`오른쪽`·`숨김`) → 장식(`방위표`·`축척 막대`·`위치도`). 위치도는 제목·요약·범례·축척·방위표를 피한 지도 안 작은 삽입도이고 PPT도 같은 자리다.
- **레이아웃 4종:** `지도 크게`·`지도 + 요약`(기본, 기존 PPT 배치 그대로)·`숫자 먼저`·`다른 타일과 나란히`. 문구 `지도 위치와 확대는 그대로 두고 배치만 바꿉니다.`
- **비교 페이지:** 2×2·3×2·3×1, 칸 수까지 타일 선택 → `비교 페이지 만들기`. 칸을 고르면 같은 지도 서랍을 쓰고, `같은 위치·확대 적용`이면 축척·이동이 모든 칸에 들어간다.
- **발표 메모·글상자:** 메모는 도구 막대의 `발표 메모 · N쪽` 팝오버(150 px 입력, 입력 600 ms 뒤 반영, `저장됨`, 되돌리기는 입력 묶음 단위, PPT 발표자 노트)에서 연다. 글상자는 T2 종류 선택→놓기→고르기→고치기 흐름을 쓰며, 상자 전체 서식만 저장한다. 빈 글상자는 PPT에 넣지 않는다.
- **내보내기(C4):** `내보내기` 아래 `role="dialog"` 팝오버(포커스 가둠, Esc로 닫고 버튼으로 복귀). `어디에 쓰실 건가요?` 쓰임 4종 `발표`(PPT·메모 포함)·`인쇄·제출`(PDF·판형 그대로·300 dpi)·`메신저·문서에 붙이기`(쪽마다 PNG, 2쪽 이상 zip)·`모두 한 번에`(zip에 PPT+PDF+`png/`). 페이지 `전체 {n}쪽`/`지금 쪽만`/`골라서`, PPT 지도 그리기 `편집 가능한 도형`/`이미지 한 장`, 파일 이름, `내보내기 전 확인`(`{n}쪽 보기`), 실행 `PPT 내려받기 · {n}쪽` 등, 진행 `{done}/{total}쪽 만드는 중…` + `취소`(취소하면 파일을 만들지 않음).
