# v2 디자인 언어 — 결정 기록

v2 화면·타일·펼침 창·PPT가 같은 모양과 같은 말로 보이게 하는 규칙이다. **사용자가 확정한 결정만** 적는다. 새 화면을 만들거나 고치는 작업(사람·실행자 모두)은 먼저 이 문서를 읽고 따른다. 여기에 없는 새 패턴이 필요하면 시안을 만들어 사용자 승인을 받은 뒤 이 문서에 추가한다.

- 적용 범위: `src/components/v2/*`, `src/lib/v2/ui/*`, `src/lib/v2/report/*`(PPT), 가이드 페이지.
- 구현 기준 코드: 숫자 서식 `src/lib/v2/ui/tile-view.ts` `formatMetricValue`·`formatDistanceM`, 레이어 색·라벨 `src/lib/v2/ui/map-layers.ts`, 대지 표식 `src/components/v2/map-figure.tsx`.
- 색 토큰 정리(하드코딩 hex → 토큰)는 W5 작업. 그 전까지 새 코드도 아래 값을 그대로 쓴다.

## 1. 기본 원칙
| 원칙 | 규칙 |
|---|---|
| 색에만 기대지 않기 | 상태·강조·대지 표시는 모양/외곽선/글자로도 구분된다(흑백 인쇄·색각 안전). |
| 화면 = 보고서 | 카드·펼침 창·PPT는 같은 컴포넌트(`MapFigure`)로 그린다. 화면에서 고정한 것은 PPT에 그대로 나온다. |
| 지도를 가리지 않기 | 지도 위 오버레이는 방위표·축척·한 줄 범례·대지 표식·고정 라벨만. 제목·출처·패널은 지도 밖. |
| 사용자 말로 쓰기 | 개발 용어·내부 id·원천 파일명(TL_SPBD_BULD 등)·영어 계절명 노출 금지. |
| 호버 전용 금지 | 마우스 호버로만 되는 기능은 없다. 같은 것을 클릭/탭/키보드로 할 수 있어야 한다. |

## 2. 글꼴
- 제목(타일 제목·화면 제목): Do Hyeon(`--font-dohyeon`), 대체 Noto Sans KR.
- 본문·숫자·라벨: Noto Sans KR(`--font-noto-kr`). 숫자가 세로로 줄 서는 곳은 `tabular-nums`.
- 타일 제목은 **말줄임 금지**(잘려서 못 읽으면 안 됨). 공간이 부족하면 핵심 숫자를 먼저 숨긴다.

## 4. 숫자·단위 (`formatMetricValue`)
- `%`, `°C`, `m/s`, `도`: 소수 1자리. 면적·밀도·인원·금액(㎡, ha, 동/㎢, 명/㎢, 원/㎡ …): 정수. 그 밖: 최대 소수 2자리.
- 천 단위 쉼표(연도 제외). 거리: 1 km 미만 `480m`, 이상 `1.2 km`.
- 값이 없으면 `미확인`. 추정값은 `추정` 배지를 붙이고 확정값과 섞어 세지 않는다(예: 건물 높이 확정/추정 분리).

## 5. 타일 카드 구조 (2026-10-06 승인, 지도 면 재구성)
1. **헤더**(지도 밖, 40 px): 점 + 제목 + 핵심 숫자. 그 아래 한 줄에 숫자의 짧은 의미 라벨(예: "1990년대 이전 준공"). 오른쪽 버튼: 보고서 체크, 펼치기 ↗, ⋯ 메뉴, ↺ 요약.
2. **지도**: 남은 높이 전부. 반경 원이 지도 높이를 채우는 축척.
3. **출처**(지도 밖, 24 px, 한 줄 말줄임 — 전체는 상세 창).
- 버튼 시각 크기 32 px, 누르는 영역 44 px 이상, 포커스 링 보임.
- ⋯ 메뉴는 팝오버(role=menu, Esc·바깥 클릭으로 닫힘, 포커스 복귀). 타일별 설정(보고서 그림, 고정 라벨 모두 끄기 등)은 여기로.

## 5-1. 머리 줄과 프로젝트 (2026-10-07, 보드 저장)
- 로고·주소 제목은 어느 폭(1440~390)에서도 한 줄 유지. 좁으면 덜 중요한 컨트롤부터 "더 보기"로 접는다.
- 저장은 **분할 버튼** 하나: `저장` 본체 + `▾`(44 px) 메뉴에 `다른 이름으로 저장`.
- 내 프로젝트 목록: 데스크톱은 팝오버/패널, 390 px는 전체 화면 시트 + 오른쪽 위 ✕ 하나(44 px). 행 = 이름·주소·반경·분석일·데이터 기준일·수정 시각, 버튼 열기/이름 변경/삭제(삭제는 확인). 빈 상태 문구로 다음 행동 안내.
- 날짜·시각 표기는 `2026-10-07 10:51` 한 형식.

## 6. 범례
- 카드: 지도 왼쪽 아래 **한 줄 알약**(반투명 흰 바탕), 많이 나온 순 최대 3개 + `+n`. `+n`을 누르면 전체 목록 팝오버.
- 펼침 창: 오른쪽 세로 목록, 항목별 개수 표시.
- 연속 범례(래스터): 얇은 막대 한 줄, 최소·최대 값만.
- 범례 이름은 같은 이름끼리 하나로 묶인다(`legendItems`가 라벨로 중복 제거) — 강조 매칭도 **범례 라벨 기준**.

## 7. 범례 강조 (⑥, 2026-10-07 승인 — 시안 https://claude.ai/artifact/DKQQRH8GueBKMSZDzQyEkR)
- 범례 항목에 올리면 그 항목 요소만 그대로, **나머지는 불투명도 20%**.
- 강조된 요소에는 **검은 외곽선**(`#111`, 화면 1.6 px 상당)을 더한다(색 구분이 어려워도 보이게).
- 누르면 강조 고정, 다시 누르거나 Esc로 해제. 터치: 탭으로 켜고 끔. 키보드: 초점이 가면 강조, Enter로 고정.
- 화면 탐색용이다 — PPT에는 반영하지 않는다.
- A05/A06 설명선: 같은 규칙으로 점과 설명 카드를 함께 흐림/외곽선.

## 8. 지도 요소 라벨 (⑦, 2026-10-07 승인)
- **호버 라벨**: 검은 바탕 흰 글자 꼬리표, 지시선. 내용 `이름 · 값`(건물 `고덕 그라시움 104동 · 2019`, 정류장 `고덕역 정류장 · 직선 480m`). 이름 없는 요소는 범례 이름.
- **고정 라벨**: 요소를 누르면 남는다. **흰 꼬리표 + 검은 테두리 + 앞쪽 작은 검은 점 + 지시선**. 고정 라벨을 다시 누르면 해제.
- 관리: ⋯ 메뉴 "고정 라벨 모두 끄기", 펼침 창 오른쪽 "고정 라벨" 목록에서 하나씩 보이기/끄기/삭제. 꺼 둔 라벨은 목록에 남고 지도·PPT에서 빠진다.
- 배치: 요소 오른쪽→왼쪽→위→아래 순으로 겹치지 않는 자리, 안 되면 지시선으로 밖에. 고정 라벨이 자동 라벨보다 우선.
- 저장: 타일별 보드 상태 → 서버 저장·다시 열기·PPT에 반영.
- 1차 범위: 벡터 지도 타일. 래스터 구간 강조, S01 3D, D22 바람장미는 2차.

## 9. 대지 표식 (2026-10-06 승인, 2안)
- 필지 윤곽: 흰 halo 선(굵기 `max(0.5r, 2.4)`) 위에 검정 `#111` 선(`max(0.2r, 1.2)`).
- 중심: 45° 흰 마름모 + 검정 테두리 + 중심 점.
- 필지가 화면에서 약 10 px보다 작거나(외곽 상자 짧은 변 기준) 필지가 없으면 크로스헤어 링.
- r: 카드 4 · 펼침 7 · PPT 10.

## 9-1. 대지 지정 화면 (2026-10-07 승인 — 시안 https://claude.ai/artifact/6ED7C1x7QFPxevtRVinfSu)
- 주소 줄 아래 지정 방식 3개(세그먼트): **주소 필지 1개** · **필지 합치기** · **구역 그리기**.
- 데스크톱: 왼쪽 지도 + 오른쪽 대지 패널(320 px). 390 px: 지도 위, 패널은 아래 시트.
- 지도: 화면 범위 필지 윤곽(회색 얇은 선, 지번 작은 글자), 고른 대지는 §9 대지 표식(흰 halo + 검은 윤곽, 합친 덩어리의 바깥 경계만) + 중심 마름모. 오른쪽 위 작은 반경 미리보기.
- 필지 합치기: 누르면 추가·다시 누르면 빼기·Alt+클릭 새로 시작, 최대 30필지. 붙어 있지 않으면 분석 단추를 끄고 이유를 경고 상자로. 도로(지목 '도') 필지가 섞이면 경고.
- 구역 그리기: 눌러서 점 추가, 첫 점(크게 표시)을 누르거나 "그리기 끝"으로 닫기, 닫은 뒤 점 끌기, 되돌리기(Ctrl+Z·⌫)·다시 그리기. 자기 교차면 경고. 면적에 `추정` 표시.
- 패널: 필지 수·면적 합·지목·대표 지번("고덕동 248-2 외 2필지"), 고른 필지 목록(✕로 빼기), 상태 한 줄(가능 ✓ / 경고). 지도 아래쪽 안내 띠에 현재 방식의 조작법 한 줄.

## 9-2. 출처 표시 (2026-10-07 승인 — 시안 https://claude.ai/artifact/AZFmfqLGkCczU9Hkv3Ugac)
- 카드: 지도 밖 출처 한 줄(말줄임 허용) + 끝에 원천 개수 칩(`출처 3`). 줄이나 칩을 누르면 펼침 창 "출처·기준일" 칸이 열린다.
- 펼침 창 출처 칸: 원천마다 표 6행 — 자료(+주 원천/보강/입력 칩)·제공처·기준일·이용조건·쓰인 곳·원문 확인(링크). 원천별 "인용문 복사", 칸 아래 "모두 복사", 복사 결과는 상태 문구로("복사됨" / 실패 시 직접 선택 안내 + 인용문 텍스트 표시).
- 인용문 형식: `제공처, 「자료」(기준일 기준), 이용조건, URL`.
- 계산 도판(일조·개방감·바람·열쾌적 등): 맨 위에 "계산 방법" 한 줄, 아래 원천은 "입력 원천"으로.
- 날짜는 기준일(원천 내용)·게시일(우리 데이터)·분석일을 섞지 않는다. 모르면 `기준일 미확인`.
- **그 타일 계산에 실제로 쓰인 원천만**(적재 provenance 기준) — 쓰지 않은 원천을 이름만 붙이지 않는다.
- PPT: 셀 아래 짧은 출처(기관·자료·기준일), 출처 슬라이드 열 = 제공처·자료 / 기준일 / 이용조건 / 원문 확인 / 사용한 타일, 각주에 분석 생성일과 "기준일은 원천 날짜" 안내. 표는 편집 가능한 텍스트.

## 10. 문구
- 사용자에게 보이는 말은 한국어, 동작은 동사로("저장", "다시 분석"). 오류는 무엇이 잘못됐고 어떻게 하면 되는지.
- 준비 안 된 타일은 "준비 중"으로 접고 개발 일정·내부 단계 이름을 쓰지 않는다.
- 출처 줄은 기관·자료 이름과 기준일만(`SOURCE_NAMES`). 이용조건이 출처 표기를 요구하는 원천은 표시 이름에 조건을 함께 적는다(예: `행정안전부 도로명주소 건물(CC BY-NC-ND)`).
