# 예정 철도 지오메트리 전수 수집 범위

> 기준일: 2026-07-17  
> 결정: 지하철·광역철도 범위에서 공사·설계·승인 사업을 전수 관리한다.  
> 비용: 기존 정적 데이터 배포 경로만 사용하며 추가 월 비용은 0원이다.

## 공개 기준

각 사업은 메타데이터를 전수 등록하되, 지도 선형은 아래 기준을 통과한 경우에만 공개한다.

| 등급 | 근거 | 지도 표시 |
| --- | --- | --- |
| A | 공식 GIS·좌표·승인 지형도면 | 실선, `high` |
| B | 공식 PDF 또는 공식 노선도를 지오리퍼런싱 | 점선, `medium` |
| C | 공식 발표의 기·종점 또는 개략도만 존재 | 점선, `low`, 역 좌표 미표시 |
| 보류 | 사업명·상태만 확인되며 노선 근거가 부족 | 지도 선형 미공개 |

운영 중인 선로와 겹치는 구간은 운영 OSM 스냅샷을 재사용할 수 있지만, 신규 구간은 반드시 해당 사업의 공식 근거를 별도로 남긴다. 예정 역·선로는 현재 역 개수, 접근성, PPT 점수에 포함하지 않는다.

## 공식 수집 경로

1. [국가철도공단 광역철도 주요사업현황](https://www.kr.or.kr/sub/info.do?m=05010402): 공사·설계 사업 상태와 공식 노선도.
2. [국토교통부 도시철도 고시](https://www.molit.go.kr/mtc/USR/I0204/m_37140/lst.jsp?gubun=4): 기본계획·사업계획 승인과 변경 고시의 원장.
3. [환경영향평가정보지원시스템](https://www.eiass.go.kr/biz/base/info/perList.do): 대안노선·평면도 등 세부 문서 후보.
4. 사업 지자체의 도시철도 사업 포털: 실제 공사·계약·변경 상태 검증.

공개 확인 결과 위 원천은 GeoJSON·SHP·KML을 제공하지 않는다. 국가철도공단의 노선도는 래스터 이미지이고, 지자체 자료도 PDF·이미지·HWP/HWPX가 주류다. 따라서 자동 API 수집이 아니라 문서별 검수형 지오리퍼런싱이 필요하다.

## 전수 후보 목록

### 1차: 국가철도공단 광역철도 13건

- 신안산선
- 충청권 광역철도 1단계(계룡–신탄진)
- GTX-A 잔여 삼성역 구간
- 삼성–동탄 광역급행철도 잔여 삼성역 구간
- GTX-B 민자구간(인천대입구–용산, 상봉–마석)
- 용산–상봉 광역급행철도
- 신분당선 광교–호매실
- 태화강–송정 광역철도
- 부전–마산 복선전철
- GTX-C
- 대전–옥천 광역철도
- 대장–홍대 광역급행철도
- 용산–강남 복선전철(신분당선 2단계)

GTX-A와 삼성–동탄은 이미 개통한 구간을 재표시하지 않고, 미개통·공사 구간만 별도 segment로 관리한다. GTX-C는 공단 표제와 개별 진행현황이 다르므로 `proposed`로 등록하고 다음 원문 확인 전 `under_construction`으로 승격하지 않는다.

### 2차: 서울·경기 지자체 사업 25건

- 서울 9호선 4단계 연장, 동북선, 위례선, 우이–신설 방학 연장, 면목선, 위례신사선
- 서울 제3차 도시철도망 제안: 강북횡단선, 난곡선, 서남선, 서부선, 서부선 남부연장, 신림선 북부연장
- 경기 도시철도망: 월곶–배곧선, 용인선 기흥–광교 연장, 수원 도시철도 1호선, 모란–판교선, 성남 도시철도 1·2호선, 김포골드라인 학운 연장, 판교–오포선, 동백–신봉선, 고양 가좌–식사선, 대곡–고양시청–식사선, 덕정–옥정선, 동탄 트램

서울 제3차 도시철도망의 제안 노선은 중앙 승인 전까지 `proposed`로 유지한다. 경기도 도시철도망의 PDF 개략도는 선형 근거는 되지만 실시 설계 선형으로 해석하지 않는다.

### 3차: 비수도권 도시철도 6건

- 부산 사상–하단선
- 부산 하단–녹산선
- 대구 도시철도 4호선(엑스코선)
- 대전 도시철도 2호선
- 광주 도시철도 2호선
- 울산 도시철도 1호선

## 수집 순서와 완료 조건

```text
사업 후보
  -> 공식 상태·원문 URL 확인
  -> 공식 도면 확보
  -> 기지 운영선과 중복 분리
  -> 지오리퍼런싱·선형 벡터화
  -> 독립 검토
  -> planned.json 공개
```

1. **공사 중 사업 우선**: 지오리퍼런싱 후 B/C 등급으로 공개한다. 이미 일부 개통한 사업은 미개통 구간만 분리한다.
2. **승인·설계·기본계획 단계**: 공식 도면이 확인된 경우에만 C 등급 개략선을 공개한다.
3. **지자체 제안 6건**: 메타데이터만 등록하며, 중앙 승인 또는 노선도 원문 확보 전에는 지도를 비워 둔다.

각 선형은 다음을 모두 충족해야 한다.

- 원문 URL, 원문 발행일, 확인일, 출처 파일 해시를 남긴다.
- 두 명의 검토 결과 또는 독립 근거 두 개가 500m 이상 상충하면 `geometry_conflict`로 보류한다.
- 공식 역 위치가 없는 경우 `stations: []`을 유지한다.
- 90일마다 상태·도면 변경 여부를 다시 확인하고, 180일이 지나면 `stale`로 표시한다.
- 운영선과 예정선을 같은 스타일·같은 지표에 섞지 않는다.

## 최초 데이터 배치

첫 배치는 기존 개략선 1건(위례과천선 강남지선)을 포함해, 공식 상태와 도면이 모두 있는 공사 중 사업부터 처리한다. 한 배치에서 검증된 선형만 `public/data/rail/planned.json`에 반영하고, 도면만 있는 후보는 별도 수집 대기 목록에 보존한다.

## 비범위

- 제4차 국가철도망 구축계획에만 등장하는 장기 후보선
- 일반·고속철도 및 화물철도
- 출처가 사설 지도, 언론 그래픽, 커뮤니티 게시물뿐인 선형
- 예정 데이터를 현재 접근성·역세권 점수로 환산하는 기능
